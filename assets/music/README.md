# Music beds

Drop `.mp3`, `.wav`, `.m4a`, `.flac` or `.ogg` files here and they show up in the
Render tab's music picker. Leave the picker on "auto" and the tool chooses one
per project — deterministically, so re-rendering the same project keeps the same
track.

You do not need to level the files yourself. The bed is normalised to −16 LUFS
before the "music under voice" setting is applied, so a quiet ambient track and a
loud one both end up the same distance below your narration. It is then
side-chain ducked against the voice, so it lifts in the gaps between paragraphs.

For this kind of video, look for something slow, sparse and without a strong
melodic hook — anything with a tune competes with the words. Sources worth a
look: the YouTube Audio Library, Free Music Archive (filter by CC), Kevin
MacLeod's Incompetech, and Blue Dot Sessions.

Check the licence of anything you use here, especially if the video is monetised.
The credits block in the Render tab lists the track name but cannot know its
terms.
