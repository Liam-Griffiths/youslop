# Number slam

Land one measured number with a clear unit and provenance.

- Variables: title <=48 characters; source <=64 characters; value: -999999..999999 (sample 42000); decimals: 0/1/2 (0); unit: 16 characters (residents).
- Motion: Count from zero through a 17-row eased atlas in 0.9 s, then hold; one number layer. No capture windows; budget 0.
- Layout/look: both 16:9 and 9:16; portrait stays within 15–80% height and left of 85% width. Instrument channel tokens; local Archivo 800/62%, Inter and JetBrains Mono for numbers. Labels wrap, data limits fail before capture; all-zero series use a labelled 0..1 scale.
- Preview: metadata samples in both aspects; midpoint poster and six-time sheet deferred to reviewer along with browser checks and timings (Chromium unavailable).
