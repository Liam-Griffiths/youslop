# Archive frame

Purpose: A local picture in an archival mount with a catalogue label.

Original layout: Inset mount, accent index tab and a ruled opaque catalogue drawer.

Inputs: title (40), catalogue (56), picture (image). All pictures are replaceable local image variables; samples are original geometric coastal studies drawn offline with Pillow. No external sources.

Theme: core default colours, token fonts, weight, radius and pace. Caption and catalogue text sits on opaque panels with border-box sizing and font-ready fitting retaining full copy in titles. Both aspects respect title safety and portrait controls.

Motion: whole-layer presets with a 0.25 s exit; zero frame captures and budget 0.
