# Counter

Count up to one measured total, then hold it for reading.

- Layout and accent: One large accent total over an open baseline. Prefix and suffix stay attached. A 0.6 s counting window, then a stable hold.
- Both 16:9 and 9:16, inside landscape title safety and portrait Shorts safety. Theme colours, font, weight, radius and pace; core default colours.
- Data: one typed `rows.value`, −999999..999999, up to two decimal places; prefix ≤3 and suffix ≤8. Numeric type scales to its bounded slot; prefix and suffix get separate lines.
- Copy: title ≤36, source ≤56; rows bounded and validated before capture. Values use typed tables and number matching (waveform has no numeric claim).
- Motion: shared presets with final 0.25 s fades; no nested layers. Counter budget 0.25: one 0.6 s window, at most 26 frames at pace 1.4 / 30 fps, within the 30-frame minimum-duration allowance.
- Review: default and alternate themes, both aspects, maximum copy and reverse seeks. Browser posters and motion review required.
