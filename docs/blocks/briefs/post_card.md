# Post Card

Purpose: Highlight a generic authored post, optional local picture and measured engagement.

Original layout: themed Instrument typography with no product or operating-system chrome. Both aspects use border-box text panels inside title safety; wide copy wraps, then ellipsises after fonts load with full copy retained in titles.

Inputs: handle (24), text (140), picture (bounded typed rows), rows (bounded typed rows), source (56). Rows are validated before capture; defaults are illustrative.

Motion: whole panels/rows use presets and a 0.25 s exit. Zero frame-window budget. Ticker uses one linear leftward path; no repeated captures.

1–3 typed count rows: label 1–24 characters, integer value 0–999,999,999 displayed with separators. Counts participate in number matching. Optional picture defaults to an original geometric river crossing drawn locally with Pillow. Accent cap and count rules.
