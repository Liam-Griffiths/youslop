# Photo stack

Purpose: Pictures dropping onto an offset pile.

Original layout: Offset mounts with an accent corner tab on each print; staggered downward arrivals.

Inputs: title (40), count (enum), picture1 (image), picture2 (image), picture3 (image), picture4 (image). All pictures are replaceable local image variables; samples are original geometric coastal studies drawn offline with Pillow. No external sources.

Theme: core default colours, token fonts, weight, radius and pace. Caption and catalogue text sits on opaque panels with border-box sizing and font-ready fitting retaining full copy in titles. Both aspects respect title safety and portrait controls.

Motion: whole-layer presets with a 0.25 s exit; zero frame captures and budget 0.
