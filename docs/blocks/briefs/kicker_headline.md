# Kicker + headline

Pair a small editorial category with a large explanatory headline.

- Variables (text limits in characters): title: headline, 72; kicker: category, 32; subtitle: deck, 96. Defaults: 'WHO OWNS THE NIGHT?' / 'AFTER HOURS' / 'How a city works while we sleep'.
- Motion: Rise the kicker, headline and deck together over 0.45 s, hold, fade out.
- Layout: 16:9 and 9:16; portrait copy stays between 15–80% height and left of the rightmost 15%. Long text wraps; chapter keeps legacy limits with smaller type.
- Look: Instrument tokens; Archivo 800 at 62% width for display, local Inter for supporting copy. Opaque panels protect picture text contrast. Optional pictures default to empty, showing the channel ground.
- Preview: default metadata copy, midpoint poster and six-time sheet in both aspects; browser generation deferred to reviewer (Chromium unavailable).
