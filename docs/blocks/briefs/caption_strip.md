# Caption strip

Purpose: An opaque full-width documentary caption band over a picture.

Original layout: Accent baseline beneath a broad opaque subtitle band; full composition width with copy constrained to title safety.

Inputs: caption (64). All pictures are replaceable local image variables; samples are original geometric coastal studies drawn offline with Pillow. No external sources.

Theme: core default colours, token fonts, weight, radius and pace. Caption and catalogue text sits on opaque panels with border-box sizing and font-ready fitting retaining full copy in titles. Both aspects respect title safety and portrait controls.

Motion: whole-layer presets with a 0.25 s exit; zero frame captures and budget 0.
