# Viewfinder

Purpose: Camera framing overlay with a fixed recording label and timecode.

Original layout: Four accent L-shaped corner marks and an opaque recording/timecode rail; static timecode, no simulated live clock.

Inputs: label (12), timecode (16). All pictures are replaceable local image variables; samples are original geometric coastal studies drawn offline with Pillow. No external sources.

Theme: core default colours, token fonts, weight, radius and pace. Caption and catalogue text sits on opaque panels with border-box sizing and font-ready fitting retaining full copy in titles. Both aspects respect title safety and portrait controls.

Motion: whole-layer presets with a 0.25 s exit; zero frame captures and budget 0.
