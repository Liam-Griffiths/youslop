# T2.10 Blocks, cards and HTML slides through the builder
Phase 2 · Size M · Depends on: T2.8
*Written 2026-11-01 (Claude Opus 5.5).*

## Goal
Blocks (Phase 12), intro/outro/chapter cards and animated custom HTML slides render
through `scene_builder.render` instead of `scenes.ensure_clip`'s every-frame capture,
and the block format declares motion with the T2.8 layer attributes.

## Why
`blocks.render` and `scenes.render_card` still screenshot every frame.
`custom_scenes.html_candidate` already delegates motion to the builder after T2.9,
but sanitised fragments are held as one static layer. Cards are short, but blocks will be used throughout videos
(lower thirds, captions, data), so they must be cheap.

## Read first
- T2.8 and `docs/scene-builder.md`.
- `app/blocks.py` (`prepare`, `render`), `app/block_authoring.py` (`check`,
  `preview`), `docs/blocks/format.md`, `docs/blocks/block.schema.json`.
- `static/blocks/*` (T12.3 batch 1 uses `data-anim` presets).
- `app/scenes.py`: `render_card`, `intro_context`, `outro_context`;
  `app/custom_scenes.py`: `html_candidate`.

## Steps
1. Block format: blocks use `data-layer` / `data-motion` (alias the existing
   `data-anim` names) and may declare `budget` for capture windows. Update the schema
   and `format.md`.
2. Convert the 20 unique built-in blocks (9 from T12.1 plus 12 from T12.3
   batch 1, which reuses `chapter`) and the card templates to layers. Preserve
   declared aspects: the 12 Text blocks support both; legacy wrappers are landscape.
3. Route `blocks.render`, `render_card`, chapter tails and block preview videos
   through `scene_builder.render`. Retain the existing HTML-slide builder route
   and support explicit sanitised layers alongside its static-fragment fallback.
4. `block check` reports the builder stats (captures, passes, capture-window frames)
   and fails a block whose capture windows exceed its budget.
5. The sanitiser (T5.2d) may allow `data-layer`, `data-start`, `data-duration`,
   `data-motion` with allowlisted values only; add adversarial tests.

## Acceptance
- All built-in blocks pass `block check` in every declared aspect (including
  both aspects for the 12 Text blocks), with zero capture-window frames unless declared.
- A 5 s lower third renders at 1080p in under 2 s on this machine (reviewer).
