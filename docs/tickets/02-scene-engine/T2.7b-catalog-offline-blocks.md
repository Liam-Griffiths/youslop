# T2.7b Make fetched Hyperframes blocks render offline
Phase 2 · Size S · Depends on: T2.7
*Written 2026-10-31 (Claude Opus 5.5) after a real fetch failed in use.*

## Goal
A block fetched with `python -m app.cli catalog fetch <name>` renders through
our scene engine with no network: its CDN GSAP and Google Fonts references are
rewritten to local files at fetch time, the rewrite is recorded, and the
licence is captured.

## Why
Checked on 2026-10-31 with `yt-lower-third` (commit `5ce6b30b`): the block
loads `https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js` and Google
Fonts (DM Sans). Our scene lint forbids remote scripts (renders must be
deterministic and offline), the fetcher stores that lint failure in
`SOURCE.json`, and `scenes._key` refuses the block. The integrity check
(`modified local catalog file`) also blocks a hand fix. So today **no block
that loads GSAP from a CDN can be used**, which is most of the catalog.
The repo is Apache-2.0 (`LICENSE.txt` arrives with each block), but
`SOURCE.json` records `"license": ""`.

## Read first
- `app/catalog.py` (fetch, integrity check, `SOURCE.json`), `app/scenes.py`
  (`_scan`, `lint`, `_key`, `/catalog/` mounts), `static/scene/runtime.js`
  (mounting `data-composition-src`), `THIRD-PARTY.md`.

## Steps
1. At fetch, after download and hashing the originals, apply rewrites to a
   copy: `<script src=".../gsap@X/dist/gsap.min.js">` → removed (the host scene
   already loads `/static/vendor/gsap/gsap.min.js`); other known GSAP CDN forms
   likewise. Google Fonts `<link>` → `@font-face` pointing at font files
   downloaded once into the block folder (or at `resources/fonts` when the
   family ships there). Any other remote script or stylesheet: keep the lint
   failure (block stays unusable, with a clear reason).
2. `SOURCE.json`: keep original hashes under `original`, add `rewritten` hashes,
   a `rewrites` list (what changed), and `license` from the repo/registry
   (`Apache-2.0`). The integrity check compares against `rewritten`.
3. GSAP version: blocks pin 3.14.x and we vendor 3.13.0. Vendor the newest
   3.14.x as well (reviewer downloads; Codex has no network) and pick by the
   block's major.minor; note the choice in the log.
4. Credit: keep `LICENSE.txt` beside the block; list fetched blocks in a
   generated `assets/catalog/NOTICE.md`, and mention Apache-2.0 catalog blocks
   in `THIRD-PARTY.md`.
5. Tests with a fixture block (mocked HTTP) covering: CDN GSAP removed, fonts
   localised, unknown remote script still refused, integrity after rewrite.

## Acceptance
- Reviewer, outside the sandbox: fetch `yt-lower-third` and two other blocks,
  mount each in a `_test` scene, capture t=0.2 and t=1.5 at quarter size: the
  block animates, fonts render, no network requests (check Chromium's network
  log is empty apart from the local server).

## Verify
```sh
.venv/bin/pytest tests/unit/test_catalog.py -q
CORKBORED_DATA=$(mktemp -d) .venv/bin/python -m app.cli catalog fetch yt-lower-third
```

## Don't
- Never fetch at render time. Never allow a remote script through.
- Don't modify the originals' recorded hashes; record both.
