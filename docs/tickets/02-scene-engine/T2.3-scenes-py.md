# T2.3 scenes.py and Jinja templates
Phase 2 · Size M · Depends on: T2.1, T2.2

## Goal
`app/scenes.py` turns a template name plus a context dict into a cached mp4
clip (or one PNG) through the CDP runner, with a lint pass on the generated
HTML and a CLI command to preview a frame.

## Why
The planners already emit JSON (cues, titles, palette). This module is the
one place that turns such JSON into HTML, so every later migration is "write
a template", not "write a renderer".

## Read first
- `app/shots.py`: `_render_item()` and `ensure_clips()` for the cache-key
  pattern (sha1 of a spec list, clips under `<project>/stage/clips/`) and
  `_sweep()`.
- `app/themes.py`: `palette(style)`.
- `app/stage.py`: `render_scene`, `capture_one` (T2.1).
- `static/scene/runtime.js` (T2.2) contract.
- `FrameSpec` (T1.1) if present; if not yet merged, use a dict of the same
  defaults and leave a `TODO T1.1` comment.

## Steps
1. Add `jinja2>=3.1` to `requirements.txt`; add `jinja2` and `markupsafe`
   to the PyInstaller spec `hiddenimports` if the build complains (note in log).
2. `app/scenes.py`:
   - `SCENE_VERSION = 1` (bump whenever runtime or shared CSS changes in a
     way that should invalidate caches).
   - `env = jinja2.Environment(loader=FileSystemLoader(STATIC_DIR / "scene"), autoescape=True, undefined=StrictUndefined)`.
     StrictUndefined so a missing context key fails loudly.
   - `context_base(project, channel=None) -> dict`: `frame` (FrameSpec dict
     or defaults), `palette` (from `themes.palette`), `vars` (channel name,
     tagline, accent, accent2, video title/subtitle), `fonts` (absolute
     `/fonts/...` URLs; add a `translate_path` rule in `stage.py` for
     `/fonts/` → `resources/fonts` if `static` does not already expose them),
     `assets_url` (the `/scene/<token>/` prefix for project files).
   - `render_html(template: str, ctx: dict) -> str`.
   - `lint(html: str) -> list[str]`: the contract checks from T2.2's
     `test_scene_contract` plus: no `Date.now(`, no bare `Math.random(`, no
     `setTimeout(`, no `repeat: -1`, no `fetch(` to a non-local URL, no
     `.play()`. Return human-readable messages; `ensure_clip` raises on any.
   - `ensure_clip(project, template, ctx, *, seconds, size, fps, key_extra=()) -> Path`:
     key = sha1 of `[SCENE_VERSION, shared asset hash, template, template/dependency content hashes, json(ctx, sort_keys), seconds, size, fps, *key_extra]`;
     path `<project>/scenes/<key>.mp4`; if present return it; else write the
     HTML to `<project>/scenes/<key>.html`, call `stage.render_scene` with
     `scene_root=<project>/scenes` and `url_path=/scene/<token>/<key>.html`,
     return the mp4. Sweep like `shots._sweep` (keep 400).
   - `capture(project, template, ctx, *, t, size) -> bytes` (one PNG) via
     `stage.capture_one`.
   - `handles(fmt: str) -> bool`: true when `static/scene/<fmt>/segment.html`
     exists (used by T2.4).
3. **Shared CSS and base template.** `static/scene/_base.css` (reset, the
   `--arrive-s`, `--exit-ratio`, palette variables, safe-area helpers:
   `.title-safe` is the inner 80 % box, `.action-safe` the inner 90 %) and
   `static/scene/_base.html` (root element with the four data attributes,
   `<link>` to base CSS, `@font-face` rules from `fonts`, a `{% block body %}`
   and `{% block script %}`). Every template extends it.
4. **CLI.** `python -m app.cli scene-preview <template> --ctx ctx.json [--t 1.5] [--out frame.png]`
   writes one PNG; `--mp4 --seconds 3` writes a clip at 480×270. Uses a
   temporary project dir when no `--project` is given.
5. Tests `tests/unit/test_scenes.py`: `render_html` of the `_test` template
   passes `lint`; a template containing `Date.now()` fails lint; cache key
   changes when `ctx` changes and not when key order changes.

## Acceptance
- `scene-preview _test/static.html --t 1.5` writes a PNG you can open.
- Second call to `ensure_clip` with the same inputs does not launch Chromium
  (log line "scene cache hit").

## Implementer notes
*Added 2026-10-26.*

- **`jinja2` is not installed** in `.venv` (confirmed 2026-10-31).
  Add it to `requirements.txt`; installation is an owner prerequisite when
  the implementation session prohibits pip installs. PyInstaller normally
  finds it through the import; only add `hiddenimports` if the build
  complains.
- Autoescape is on; put JSON into a page with `{{ ctx | tojson }}` inside a
  `<script>`, never with `| safe`.
- Fonts already live in `resources/fonts/` (ArchivoBlack, ArchivoNarrow,
  Caveat, CormorantSC, EBGaramond, Inter, JetBrainsMono, ...). The stage
  server serves only `/static/` and `/models/`; add `/fonts/<name>` →
  `paths.resource_root() / "resources" / "fonts" / name` in
  `translate_path`, with the same no-`..` rule. Use `@font-face` with
  `font-display: block` so `document.fonts.ready` actually waits.
- Cache-key pattern to copy: `shots.ensure_clips` / `_render_item`
  (sha1 of a JSON list, `sort_keys=True`, files under
  `<project>/stage/clips/`). Include the template file's **content hash**
  rather than its mtime (mtime changes on `git checkout` and would bust
  every cache); also hash `runtime.js` and `_base.css` into `SCENE_VERSION`
  automatically:
  ```python
  def _asset_hash() -> str:
      h = hashlib.sha1()
      for p in (SCENE_DIR / "runtime.js", SCENE_DIR / "_base.css", VENDOR_GSAP):
          h.update(p.read_bytes())
      return h.hexdigest()[:8]
  ```
- `lint()` — the cheap version is a list of regexes over the rendered
  HTML **plus** every mounted component file. Strip `<!-- -->` comments
  before matching (the registry components describe banned things in
  comments). Also reject `navigator.gpu` (WebGPU blocks such as `aurora`
  will not render headless) and `<script src="http` (remote scripts).
- `ensure_clip` must call `stage.render_scene` **outside** any
  `store.lock_for(pid)` block; rendering takes seconds and the UI polls.
- `scene-preview` CLI: when no `--project`, use
  `tempfile.mkdtemp()` as the scene root; you do not need a Project for a
  test template, so make `context_base(project=None)` work with defaults.
- Keep `capture()` writing a PNG to disk too
  (`<project>/scenes/<key>_<t>.png`) so the review tools (T3.1) can reuse it.
