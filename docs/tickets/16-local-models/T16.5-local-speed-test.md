# T16.5 Speed test and thinking advice in Check LM Studio
Phase 16 · Size S · Depends on: T16.1
*Written 2026-11-08 (Claude Opus 5.5) after live local-model runs.*

## Goal
"Check LM Studio" can run a short timed test that reports tokens per second
and recommends settings for this machine and model.

## Why
The same project took about 4½ minutes on Granite 4.1 8B and 45+ minutes on
Qwen 3.5 9B with thinking on. Nothing told the owner that beforehand. One small
call answers it: speed, and whether the model thinks.

## Read first
- `app/llm.py`: `local_probe`, `_complete_lmstudio`, `_lmstudio_effort`.
- `app/main.py`: `GET /api/llm/local`.
- `static/js/tabs/settings.js`: `localModelCheckRow`, `checkLocalModel`.

## Steps
1. `llm.local_speed_test()`: one small prompt (ask for a JSON array of five
   short strings) with thinking left on (no `reasoning_effort`) and
   `max_tokens` 1,024. Uses T16.1's streaming to measure: time to first token,
   generation speed (tokens/s), and reasoning tokens versus answer tokens.
2. Advice, worked out from the numbers rather than the model name:
   - thinks (reasoning tokens > 0) and speed under 30 tok/s: recommend
     "Local model thinking: Never", and estimate the minutes a one-minute test
     project takes each way;
   - context under 16k: the existing warning;
   - speed under 5 tok/s: suggest a smaller model or GPU offload.
3. `POST /api/llm/local/speed` runs it as a job (it can take a minute or two
   on a slow machine), so the status line from T16.1 shows progress.
4. Settings: a "Test speed" button beside "Check LM Studio"; the result line
   shows the numbers and the advice. It says it sends one short prompt.

## Acceptance
- Unit test with a fake stream: speed and the reasoning/answer split are
  computed correctly, and the advice text matches each branch.
- Reviewer live check on the owner's LM Studio: Qwen 3.5 9B is advised to turn
  thinking off; Granite 4.1 8B is not.

## Verify

```sh
CORKBORED_DATA="$(mktemp -d)" .venv/bin/pytest tests/unit -q
```

## Don't
- Don't run the test on page load or during setup automatically.
- Don't change settings automatically; advise only.

## Implementer notes
- Estimates for a one-minute `--test` project, measured on the owner's
  machine: about 12 model calls; script steps produced 4,000–8,000 reasoning
  tokens each with thinking on and about 1,000 answer tokens; chores 100–1,000
  tokens.
