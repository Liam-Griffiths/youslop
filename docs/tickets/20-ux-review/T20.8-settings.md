# T20.8 Settings: sections in order, only the fields that apply
Phase 20 · Size M · Depends on: — · Findings: UX-11, UX-28
*Written 2026-11-11 (Claude Opus 5.5) from the T20.1 review.*

## Goal
Settings opens on what matters, shows only the selected backend's fields,
and has a section nav and a save bar that never covers content.

## Why
The page is about 7,000 px long:
- Speech-to-text (optional) comes before Writing model (essential).
- Every provider's keys and paths show whatever the backend is.
- The sticky "Save settings" overlaps headings and is half hidden behind
  the jobs strip.
- Developer copy explains Chromium versus Pillow.

Screenshots: `j7-01`, `j7-03`, `j7-05` in `docs/ux-review/2026-11-11/`.

## Read first
- `static/js/tabs/settings.js`;
- `app/main.py` settings endpoints;
- `app/settings.py` field keys, groups and backend choices;
- `docs/local-models.md` (the LM Studio fields).

## Steps
1. **Order.** Writing model, Voices, Research, Archives, Speech-to-text,
   Publishing, Rendering, Appearance, Packs, General.
2. **Section nav.** A sticky left list on wide windows, a select on narrow
   ones. Each section is a link target (`#/settings/writing` and so on).
3. **Fields for the chosen backend.** Under Writing model, show the
   selected backend's fields. Fold the other providers' keys into "Other
   providers". The same applies to Speech-to-text engines.
4. **Save bar.** Sits above the jobs strip, with padding so the last
   section scrolls clear of it. Show "Unsaved changes" when the form is
   dirty.
5. **Copy.** Remove the "New-channel cards: Chromium scenes …" line, or
   reword it as "Opening slates draw in Chromium when it's installed".
6. Add snapshot harness cases for the top of Settings and a scrolled section
   at 1280×720. Browser capture and visual checks are reviewer-run.

## Acceptance
- With LM Studio selected, no OpenAI, DeepSeek or xAI key fields are
  visible until "Other providers" is opened.
- The save bar never overlaps a field at 1280×720.
