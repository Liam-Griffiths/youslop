# T20.3 One app dialog, and a theme pick you can cancel
Phase 20 · Size M · Depends on: — · Findings: UX-02 (P1), UX-07
*Written 2026-11-11 (Claude Opus 5.5) from the T20.1 review.*

## Goal
A small shared dialog helper (`appConfirm`, `appPrompt`, `appChoose`) built
on the existing `.studio-dialog` styles. The channel theme pick uses it with
a real Cancel. The rest of the native dialogs move over in T20.3b.

## Why
- Picking a channel theme opens `confirm()`, and its Cancel means "colours
  only", so a misclick always overwrites the channel's colours. Channels
  have no undo. (`static/js/tabs/channels.js` `pickTheme`;
  `docs/ux-review/2026-11-11/j4-04-kitchen.png`.)
- About 20 actions use native `prompt()`/`confirm()`. They're unstyled,
  block the window, and webview support varies by platform.

## Read first
- `docs/design/studio-flow.md` §5 (components, accessibility);
- the `.studio-dialog` rules in `static/styles.css` and the code that opens
  the jobs drawer and shortcuts dialog;
- `static/js/tabs/channels.js` `pickTheme`.

## Steps
1. **The helper.** Add `static/js/ui/dialog.js` with promise-returning
   helpers, built on `<dialog>`:
   - `appConfirm({title, body, ok, cancel, danger})` resolves to
     true/false;
   - `appPrompt({title, label, value, ok})` resolves to a string or null;
   - `appChoose({title, body, choices:[{id,label,primary}], cancel})`
     resolves to an id or null.

   Each one traps focus, closes on Escape (resolving as Cancel), returns
   focus to the opener, labels its input with `<label for>`, and uses one
   accent button. Add the script tag in `static/index.html`.
   Keep the existing `studioDialog`, `pictureDialog`, `libConfirm` and
   `editToolKey` APIs as shared-helper adapters. `tlModal` must observe both
   legacy `.modal` editors and `<dialog>` editors when refreshing the cut.
2. **Theme pick.** `pickTheme` uses `appChoose` with three choices: "Use
   colours and templates" (primary), "Colours only" and "Cancel". Cancel
   changes nothing. After applying, show a toast with an Undo action that
   restores the previous colours and templates. Keep the previous values in
   memory; a server endpoint isn't needed if the PATCH accepts them.
   The theme endpoint also changes grade, frame pacing and end-screen slot
   count; Undo must restore these too using the existing channel PATCH.
3. **Tests.** Add GJS tests for the helper (Escape, focus return, resolve
   values) and for the cancel path of `pickTheme`.

## Acceptance
- Clicking a theme and choosing Cancel leaves the channel byte-identical.
- Undo after applying restores the previous colours and templates.
- The keyboard alone can open, choose and cancel.
