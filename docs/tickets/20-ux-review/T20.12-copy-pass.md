# T20.12 Copy pass: sentence case and wrong empty states
Phase 20 · Size S · Depends on: — · Findings: UX-10, UX-12, UX-15, UX-21, UX-25, UX-27
*Written 2026-11-11 (Claude Opus 5.5) from the T20.1 review.*

## Goal
The copy follows the guide: sentence case, plain words, empty states that
match their section.

## Why
- **Wrong empty state.** The channel page's empty video list says "No music
  yet. Add a track above." (`j4-03-channel.png`).
- **Footage start.** Home says a footage start is "coming with footage
  integration", while the same page lists shoots (`j1-02-home.png`).
- **Footage logger.** It shows "Footage unavailable" while the clip plays
  (`j6-02-shoot.png`).
- **Lowercase controls.** Many controls are lowercase (see below).
- **Try it labels.** Blocks Try it labels show raw types: "title · text",
  "decimals · enum".
- **Script import.** The "too short" toast doesn't give the minimum, and
  Length stays active in script mode.

## Steps
1. **Sentence case.** Fix the start of each label:
   - "save project file…" → "Save project file…"; "dismiss" → "Dismiss";
   - "previous", "next" and "jump to next blank" → "Previous", "Next",
     "Jump to next blank";
   - "check the microphone" → "Check the microphone";
   - "draw all", "loop picture", "connect it", "download" → "Draw all",
     "Loop picture", "Connect", "Download";
   - "channel setup", "all channels", "+ new video", "← videos" → "Channel
     setup", "All channels", "New video", "Videos";
   - "browse…", "add folder", "choose a file", "add to library" →
     "Browse…", "Add folder", "Choose a file", "Add to library";
   - "no folders linked yet" → "No folders linked yet. Add one above.";
   - "script · error/done" job labels → "Script · failed" and "Script ·
     done".

   Mono metadata stays lowercase where it's data, such as "0:09 · in the
   cut".
2. **Channel empty state.** "No videos yet. Start one with New video."
3. **Home footage option.** Either enable "A footage shoot" when shoots
   exist (pre-selecting the shoot and the Footage source), or change the
   note to say plainly what's missing. Owner question G2 decides which; ask
   in the ticket log before building the enable path.
4. **Footage logger box.** Hide "Footage unavailable" while the proxy
   plays. When the original is missing, say "Original file not found:
   <name>".
5. **Try it labels.** Use the variable's label, falling back to its
   title-cased name. Types go in `title` only.
6. **Script import.**
   - Toast: "Paste at least 120 words (you have N)."
   - Disable Length in script mode, with "Set by your script".
7. Add a unit test that fails if the strings "No music yet" appear outside
   the music section, and on the 120-word message.

## Acceptance
- The listed strings are fixed. A grep for the old lowercase labels in
  `static/js` finds none of them.
