# T20.10 Plan board fit, readable Check findings
Phase 20 · Size M · Depends on: — · Findings: UX-16, UX-17, UX-19, UX-29 (guide question G3)
*Written 2026-11-11 (Claude Opus 5.5) from the T20.1 review.*

## Goal
The Plan board shows all its chapters and full beat titles. Check findings
read as sentences in Script, Edit and Review.

## Why
- **Plan.** The 6th chapter column is clipped with no scroll cue. Beat
  titles truncate, and the thesis is a one-line input that cuts off long
  text. "Write the script from this board" is disabled with no reason
  (`j2-10-plan.png`, `j2-01-start.png`).
- **Check.** Findings read as debug output: "Numbers disagree: narration
  [1875, 1870, about 45]; block [1.5 minutes, 5 minutes]. Unmatched: about
  45. · open" (`j2-15-publish.png`).
- **Script.** The findings column squeezes the text and doubles
  punctuation: "1868.: The" (`j2-11-script.png`).

## Read first
- `static/js/tabs/plan.js`;
- `app/check.py` (the `number_match` message);
- `static/js/tabs/script-check.js`;
- the finding row component used in Script, Edit and Review.

## Steps
1. **Plan columns.** The chapter row scrolls horizontally with a visible
   scrollbar and a fade at the clipped edge. Beat titles wrap to two lines.
   The thesis becomes an auto-growing textarea.
2. **Disabled reason.** When "Write the script from this board" is
   disabled, show the reason beside it: "Add at least one beat first".
3. **number_match wording.** Rewrite the message as one sentence: "The block
   shows 1.5 minutes and 5 minutes, but the narration doesn't say them." Or
   for numbers spoken but not shown: "The narration says 467, 130 and 136;
   the block doesn't show them." Keep the data on the finding for Fix.
   **Owner question G3** (is it too strict?) stays open; don't change the
   levels here.
4. **Finding row text.** Drop the trailing "· open" state word when the
   state is open; show "dismissed" and "kept" as chips.
5. **Script check column.** Give the message the full row width with the
   buttons under it. Join quoted facts with a single space, so ".:" never
   appears.

## Acceptance
- On the example, all six Plan chapters can be reached and beat titles are
  readable.
- No Check message contains "[" or "Unmatched:".
