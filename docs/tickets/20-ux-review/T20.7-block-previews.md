# T20.7 Block previews: no seek race, no broken images
Phase 20 · Size S · Depends on: — · Findings: UX-08, UX-09
*Written 2026-11-11 (Claude Opus 5.5) from the T20.1 review.*

## Goal
Themed block previews either render or say "Preview failed. Try again."
While they render, cards show the existing "Poster pending" placeholder.

## Why
- **Seek race.** The channel Block theme preview intermittently fails with
  "StageError: TypeError: window.__seek is not a function". The server
  logged a 500, and it didn't reproduce on a rerun, so it's a race:
  `__seek` is evaluated before the block runtime defines it
  (`j4-06-block-theme.png`).
- **Broken images.** In Blocks "Preview as <channel>", cards show
  broken-image alt text while their themed posters render
  (`j4-08-blocks-as-channel.png`).

## Read first
- `app/block_authoring.py` (the evaluate calls around `window.__seek`);
- `app/block_library.py` (`theme_sheet`, `preview`) and `app/main.py`
  (`block_theme_sheet`, `block_preview`): the current preview entry points;
- `app/scene_builder.py` `_value`;
- `app/stage.py` (CDP helpers);
- `static/js/tabs/blocks_browser.js` (poster `<img>`).

## Steps
1. **Wait for the runtime.** Before the first `__seek`, wait with a bounded
   poll (for example 5 s) until `typeof window.__seek === 'function'`.
   Retry the capture once on a StageError, then return a clean 409/503 with
   "Preview failed". Put runtime readiness in the shared `stage._run_cdp`
   path, and share capture retry handling between `theme_sheet` and `preview`.
2. **Placeholders.** Themed poster `<img>`s start hidden behind the
   placeholder and swap in on `load`. On `error`, show "Preview failed ·
   Retry".
3. Add a unit test with a fake CDP that defines `__seek` late.

## Acceptance
- 20 consecutive channel block-theme previews succeed in the probe.
- No broken-image icon or alt text ever shows on the Blocks grid.
