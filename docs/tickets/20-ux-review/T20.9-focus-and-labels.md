# T20.9 Focus ring everywhere, and a label on every field
Phase 20 · Size S · Depends on: — · Findings: UX-13, UX-14
*Written 2026-11-11 (Claude Opus 5.5) from the T20.1 review.*

## Goal
The guide's focus ring (2 px `--cool`, offset 2 px) appears on every
focusable control. Every field has a visible micro-label linked with
`for`/`id`.

## Why
- **Focus ring.** Outside dialogs and the timeline, focus falls back to the
  browser's 1 px auto outline, or is suppressed by input/editor resets.
- **Labels.** Review & publish's thumbnail kicker (`#thumbkick`) and the
  description textarea (`#desc-text`) have no label. Library's "Add a single
  file" fields are labelled only by placeholders (`j2-15-publish.png`,
  `j2-22-library-tab.png`).

## Read first
- `docs/design/studio-flow.md` §5 accessibility;
- the `:focus-visible` rules in `static/styles.css`.

## Steps
1. **One focus rule.** Add a global `:root :focus-visible { outline: 2px solid
   var(--cool); outline-offset: 2px; }` after the existing selection outlines.
   The root selector gives it enough specificity to win over selected cards;
   remove the higher-specificity input outline reset. Remove redundant local
   copies and keep the timeline's inset offset after the global rule.
2. **Labels.** Add micro-labels to the kicker, the description and the
   Library add-file fields (title, tags, author, licence, source page).
   Keep the placeholders as examples.
   Include the newer shared dialogs, theme builder, Edit agent, Edit bar and
   Add panel, and Settings section list in the sweep. Retain valid wrapping
   labels; name compact contextual controls with ARIA where appropriate.
3. **An audit test.** Extend `scripts/ui_snapshots.py` (or add a unit test
   on its output) so every route fails on a visible input, select or
   textarea without a label or `aria-label`.
   Audit every captured state, including controls below the fold and opened
   menus/dialogs; skip invisible controls. Accept valid `aria-labelledby`
   references as accessible names too. Browser execution is reviewer-run.

## Acceptance
- The label audit is clean on every snapshot route.
- Tabbing through Home, Script and Review & publish shows the cool ring on
  each stop.
