# T20.2 Missing recordings: find them, name them, keep mixing
Phase 20 · Size M · Depends on: — · Findings: UX-01 (P1)
*Written 2026-11-11 (Claude Opus 5.5) from the T20.1 review.*

## Goal
If a take's file is missing on disk, the app says so in plain words and
names the paragraph. The rest of the video still mixes and plays.

## Why
In the review, deleting one draft take from disk caused three problems:
- Voice still showed "0:09 · in the cut".
- Check reported 0 P0.
- Edit's whole sound mix failed with "FFError: ffmpeg failed: [in#0 @ 0x…]
  … /tmp/…/takes/kokoro/sab421ba0.2.wav".

Nothing told the user which paragraph was affected or what to do.
Screenshots: `docs/ux-review/2026-11-11/j8-02-missing-take.png` and
`j8-03-edit-missing.png`.

## Read first
- `app/check.py` (how findings are built and levelled);

## Steps
1. **Check.** Add a check that raises a P0 for every current take whose
   processed file is missing. This covers slide takes on every track and
   placed sponsor takes under the project folder, plus inserts with audio
   resolved through their footage manifest. Message: "Recording for
   ¶N is missing on disk (takes/…/name.wav)." Offer a fix action to re-voice
   with a draft voice. A take with no file but a `raw_path` that exists says
   "Reprocess" instead.
2. **Voice.** A row whose take file is missing shows "missing" in `--bad`
   with text (not colour alone). The takes panel says "This file is missing
   on disk. Re-voice, record again, or put the file back." with Re-voice and
   Record buttons. Never touch history entries.
3. **Mix.** The timeline sound and render mixes substitute silence of the
   take's recorded duration for a missing file and log a warning naming the
   paragraph. A missing file never fails the whole mix. The Edit message line
   then says "Sound mixed without ¶N: its recording is missing."
4. **Render gate.** A full render is still refused while a P0 is open, as
   now. The P0 from step 1 is what blocks it.

## Acceptance
- Delete one take file in a temp copy of the example. Check shows exactly
  one P0 naming that paragraph. Voice marks the row. Edit plays with silence
  there and names the paragraph. There's no raw ffmpeg text in any toast.
- No recording file is created, removed or rewritten by the check or the
  mix.
