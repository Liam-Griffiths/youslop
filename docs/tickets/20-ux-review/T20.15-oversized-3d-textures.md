# T20.15 3D models with oversized textures render untextured
Phase 20 · Size S · Depends on: — · Found 2026-11-11 (Claude Opus 5.5) while building the site's 3D examples

## Goal
A model whose textures are too large for the renderer still renders with its
textures. The user is told when a texture was reduced, and the original file
is never changed.

## Why
The owner's Westminster Abbey scan (182 MB GLB, a single 4096×4096 baseline
JPEG of 18 MB) rendered **flat grey** in both places:
- on the intake screen;
- in the stage renderer: segment previews and shots.

The only sign was a console line: `THREE.GLTFLoader: Couldn't load texture
blob:…`. The A380, with 20 smaller PNG textures, rendered fine.

Re-encoding the same texture at 2048×2048 (JPEG q88, 2.2 MB) in a scratch
copy fixed both. Scans with one huge atlas are common, so users will hit
this, and nothing tells them why their model is grey.

## Read first
- `app/models3d.py` (`add`, `read_glb_json`, manifest fields);
- `static/stage/core.js` (the `GLTFLoader` load);
- `static/stage/intake.js`;
- `docs/3d-explainer.md` (Intake v2).

## Steps
1. **Find the limit.** Measure it on this machine's headless path (`--use-angle`
   as `app/stage.py` sets it) and in the desktop webview, using a synthetic
   GLB with one JPEG texture at 2048, 4096 and 8192, and one PNG at 4096.
   Record which fail, and whether the cause is size, bytes or decode time.
   Write the results in the Log.
2. **Make a render copy.** On `models3d.add`, and for existing models on
   next open, when any embedded texture exceeds the limit, write
   `model.render.glb` beside `model.glb`. In the copy, oversized textures are
   re-encoded at most at the limit; everything else is unchanged. The stage
   loads the render copy when it exists. The original stays the source of
   truth for export.
3. **Say so.** The intake screen lists "Texture reduced from 4096 to 2048
   px for rendering" under the model's facts.
4. **Never fail silently.** If a texture still fails to load, the intake and
   the shot result carry a visible warning, not just a console line.
5. Add a unit test that rewrites a synthetic GLB with an oversized texture
   (buffer views re-packed, 4-byte aligned) and round-trips with
   `read_glb_json`.

## Acceptance
- The Abbey scan renders textured in a segment preview without a manual
  re-encode.
- `model.glb` is byte-identical before and after.
