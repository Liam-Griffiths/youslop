# T0.9 CLAUDE.md and repo hygiene
Phase 0 · Size S · Depends on: T0.7

## Goal
A `CLAUDE.md` at the repo root tells any agent how the codebase is shaped,
how to run and test it, and the rules it must follow. Build output is gone
from the working tree.

## Why
The ticket system assumes an agent can start cold. `CLAUDE.md` is what it
reads first.

## Read first
- `docs/tickets/README.md` (the rules; do not duplicate them, link them).
- `README.md`, `NEXT_STEPS.md`, `docs/3d-explainer.md` headings.
- `.gitignore`.

## Steps
1. Write `CLAUDE.md` (keep it under 150 lines):
   - What the product does in three sentences.
   - Run and test commands (same as `docs/tickets/README.md`).
   - Architecture map: pipeline stage → file. Research `app/research.py`;
     script `app/script_gen.py`; assets `app/media/`, `app/tts.py`,
     `app/audio.py`; render `app/render.py` (ffmpeg photographic path),
     `app/cuts/` (drawn), `app/stage.py` + `static/stage/` (3D in Chromium),
     the planned scene module (after T2.3; do not name a nonexistent path); UI `static/app.js` tabs, `static/timeline.js`;
     storage `app/store.py`, `app/schema.py`, `app/paths.py`; jobs `app/jobs.py`.
   - The jobs pattern: `jobs.start(kind, pid, fn(progress))` and the
     `with store.lock_for(pid): p = store.load(pid); ...; store.save(p)` dance.
   - Rules: link `docs/tickets/README.md`; restate the four non-negotiables
     in one line each (no Node; no front-end build step; preview one section
     cheaply, never the whole cut; 3D solver rules hold for any model).
   - Brand rule: names come from `app/brand.py`; never hard-code "Corkbored".
   - Where the work queue is: `docs/tickets/PROGRESS.md`.
2. Delete `build/`, `dist/`, `.idea/`, and generated `__pycache__/` directories outside `.venv/` and
   protected owner-data directories from the working tree (they are gitignored and untracked; confirm with
   `git status --ignored` before deleting).
3. Move the still-open items of `NEXT_STEPS.md` into `docs/roadmap.md` (most
   are already tickets; list which ticket covers each) and reduce
   `NEXT_STEPS.md` to a pointer to `docs/tickets/PROGRESS.md`.

## Acceptance
- `CLAUDE.md` exists and every path it names exists.
- `git status --ignored` no longer lists `build/`, `dist/`, `.idea/`.

## Verify
```sh
for p in $(grep -o '`[a-zA-Z0-9_/.-]*\.\(py\|js\|md\)`' CLAUDE.md | tr -d '`'); do [ -e "$p" ] || echo "missing $p"; done
git status --ignored --short | grep -v '^!! \.venv' | head
```

## Don't
- Do not delete `.venv`, `projects/`, `channels/`, or `assets/`.
