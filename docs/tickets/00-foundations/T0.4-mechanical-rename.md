# T0.4 Mechanical rename
Phase 0 · Size M · Depends on: T0.1, T0.2, T0.3

## Goal
Every user-visible "Youslop" and every 🪣 becomes Corkbored, through
`app/brand.py` where code reads it and as a literal where it cannot.

## Why
See `docs/roadmap.md` §2. The name is the product's first impression.

## Read first
Run this and read every hit; it is the work list:
```sh
grep -rniI 'youslop\|🪣' --exclude-dir=.venv --exclude-dir=.git --exclude-dir=node_modules --exclude-dir=docs . | grep -v '^./projects/\|^./channels/'
```

## Steps
Work file by file. Prefer `brand.NAME` / `brand.SLUG` in Python; literals in
HTML, shell, spec and docs.

1. **Python**
   - `app/main.py`: `FastAPI(title=brand.NAME)`; the `.youslop-style.json`
     filename becomes `f".{brand.SLUG}-style.json"` (keep reading the old name
     too if that file is read back anywhere; check).
   - `app/desktop.py`: window title, menu label, thread name.
   - `app/__main__.py`: log file name `f"{brand.SLUG}.log"`; on startup, if
     the old `youslop.log` exists and the new one does not, rename it once.
     Logger root name; argparse description.
   - `app/llm.py`, `app/desktop.py`: logger names `youslop.*` → `f"{brand.SLUG}.*"`.
   - `app/stage.py`, `app/cuts/__init__.py`: tempdir prefixes.
   - `app/media/providers.py`: the Storyblocks default project id string.
   - `app/config.py`: user agent string.
2. **Front end**
   - `static/index.html`: `<title>`, favicon (temporary: a plain SVG with the
     letter R in the accent colour; T6.2 replaces it), the `.brand` mark and
     wordmark markup. Remove the bucket drip CSS from `styles.css` (search
     `.mark`, `.drip`).
   - `static/app.js`: every "Youslop" string (about ten; grep). The guide page
     copy (`#/guide`) should read naturally with the new name.
3. **Build and scripts**
   - `youslop.spec` → `corkbored.spec` (`git mv`); inside, `name=` and the
     `.app` bundle name. Update `README-BUILD.md` and the build commands in
     `README.md`. Update `build_entry.py` if it references the spec name.
   - `scripts/make_icon.py`: stop drawing the emoji; draw the letter R for now
     (T6.2 does the real mark). Regenerate `resources/icon*`.
   - `run.sh`, `docker-compose.searxng.yml` container name.
4. **Docs**: `README.md` (title, pitch, install paths; add a short
   "History" section: the project began as Youslop, a joke about slop, and
   the renderer it grew is now serious), `THIRD-PARTY.md`, `NEXT_STEPS.md`
   header, `docs/3d-explainer.md` mentions, `tests/stage/suite.py` docstring.
5. Leave these as they are, on purpose: `brand.LEGACY_*` constants, the
   compatibility shims from T0.2 and T0.3, git history, the `projects/` and
   `channels/` dev data.

## Acceptance
- The grep from **Read first** lists only `app/brand.py`, the compatibility
  shims, the README history section and this ticket folder.
- App starts; window title, sidebar wordmark, settings page and guide page
  all say Corkbored.
- `pyinstaller --noconfirm corkbored.spec` is not run here (slow); just confirm
  the spec parses: `python -c "compile(open('corkbored.spec').read(),'spec','exec')"`.
