# T0.5 Test scaffold and graph goldens
Phase 0 · Size M · Depends on: —

## Goal
`pytest tests/unit` exists, runs in under two seconds, and guards the three
things that break silently: the filtergraph string, the timing arithmetic and
cue placement. A slow, opt-in visual test does one SSIM check.

## Why
`NEXT_STEPS.md` §4 says it: every risky change in this codebase is a
filtergraph edit that moves a pixel or a second with no error. Phases 1, 2
and 5 all edit `render.py`. Nothing may land there without these tests.

## Read first
- `app/render.py`: `_render_segment` (the filtergraph is assembled inside it
  and passed to ffmpeg near the end), `_slide_durations`, `_picture_groups`,
  `HEAD_PAD`, `TAIL_PAD`, `_build_proxy` (reads the `T/2` offset assumption).
- `app/audio.py`: `paragraph_gaps`.
- `app/cuts/kit.py`: `place`.
- `tests/stage/suite.py`: `ssim()` near line 204 and `sheet()` near 187.
- `app/schema.py`: `Project`, `Slide`, `Take`, `new_project`.

## Steps
1. Add `requirements-dev.txt` with `pytest` pinned to the installed version.
   Use the existing `.venv`; do not install packages during this ticket.
2. `tests/conftest.py`: put the repo root on `sys.path`; set
   `YOUSLOP_DATA`/`CORKBORED_DATA` to a temp dir so nothing touches real data.
3. **Fixture**: `tests/fixtures/project_min/project.json`, a documentary-format
   project with three slides, two of which have takes. Takes point at
   `takes/kokoro/take_a.wav` and `take_b.wav` inside that fixture folder:
   generate them once with
   ffmpeg (`-f lavfi -i sine=frequency=440:duration=2.5`), include the files
   (tiny). Add a helper `tests/_fixtures.py: load_project()`.
4. **Extract the graph builder.** In `render.py`, the photographic branch of
   `_render_segment` builds `inputs`, a `filter_complex` string and a final
   label before calling ffmpeg. Move that assembly into a graph-building
   function (retaining title PNG and stage side effects)
   `_segment_graph(project, group, seg_len, size, fps, ...) -> tuple[list[str], str, str]`
   (inputs, graph, last_label). `_render_segment` calls it and passes the
   result to ffmpeg. Behaviour must be identical: diff the ffmpeg command
   before and after on the fixture by logging it.
5. `tests/unit/test_graph_golden.py`: for the fixture, call `_segment_graph`
   for (a) documentary full size, (b) essay full size, (c) documentary at
   preview size. Compare to `tests/golden/*.txt`. On first run write the
   goldens. Add a `--update-goldens` option via `conftest.py` and a comment:
   "update deliberately, say why in the commit".
6. `tests/unit/test_timing.py`: with the fixture, assert that every
   paragraph starts at the same moment in picture time and in the narration
   bed. Picture side: `_segment_timing` (segment file = screen time + one
   crossfade `T`; voice begins `T/2` into the file, plus `HEAD_PAD` on the
   first). Narration side: `build_narration(lead_in=T/2 + pre_slides)` puts
   take *k* at `lead_in + HEAD_PAD + sum(take_j + gap_j for j < k)`.
   *(Corrected 2026-10-26: this step used to say `seg_len/2`; the offset is
   `T/2`, half the transition, not half the segment.)*
7. `tests/unit/test_place.py`: `kit.place` returns starts that are
   non-decreasing, the first cue starts at 0, every hold is at least the
   minimum, and the total never exceeds `length`.
8. Move `ssim()` from `tests/stage/suite.py` into `tests/_ssim.py` and import
   it back in `suite.py` so the 3D suite is unchanged.
9. `tests/visual/test_ssim.py`, skipped unless `YS_VISUAL=1`: render one
   3-second documentary segment of the fixture at preview size via
   `render.preview_segment` (or `_render_segment` directly), compare its
   frame at 1 s to
   `tests/golden/segment_doc_preview.png` with SSIM > 0.99.
   On the first run, save that frame as the reference (no second render).
   Later reference updates require `--update-goldens`.
10. Add a `tests/README.md` with the three commands.

## Implementer notes
*Added 2026-10-26 after reading `render.py`. Read before step 2.*

**Facts the ticket text does not say:**
- The documentary format's key is `"kenburns"`, not `"documentary"`
  (`schema.Style.format`). Fixture: `"style": {"format": "kenburns"}` and
  `{"format": "essay"}`.
- `config.DATA` is computed **at import time**, and this checkout has a
  `projects/` folder, so without an override every test writes into the
  repo. `tests/conftest.py` must set the env var *before* anything imports
  `app`:
  ```python
  # tests/conftest.py
  import os, sys, tempfile, pathlib
  ROOT = pathlib.Path(__file__).resolve().parents[1]
  sys.path.insert(0, str(ROOT))
  _DATA = tempfile.mkdtemp(prefix="corkbored-test-")
  os.environ["YOUSLOP_DATA"] = os.environ["CORKBORED_DATA"] = _DATA   # before any `import app`

  def pytest_addoption(parser):
      parser.addoption("--update-goldens", action="store_true")
  ```
  Then a session fixture that copies `tests/fixtures/project_min/` into
  `<_DATA>/projects/ptest0001/` and returns `store.load("ptest0001")`.
- `Slide.take` is a plain **dict**, not a `Take` object. A minimal slide:
  `{"id": "s1", "narration": "...", "take": {"path": "takes/kokoro/s1.wav",
  "duration": 2.5}, "chosen_id": "c1", "candidates": [{"id": "c1",
  "kind": "image", "local_path": "media/pic.jpg"}]}`. `_chosen()` returns
  `None` (graded slate) if `local_path` is missing, which is a valid but
  boring golden; include one real picture so `_cover_crop` runs. Generate it
  once: `ffmpeg -f lavfi -i testsrc2=s=640x360 -frames:v 1 pic.jpg`.
- `Project.from_dict` calls `sync_takes()`, which may set `voice_track`.
  Fine, but set `"voice_track": "kokoro"` in the fixture so it is explicit.

**Extracting `_segment_graph`.** The photographic branch is
`render.py` from `essay = style.format == "essay"` (~line 554) to just
before `ffutil.run([...])` (~733). Move exactly that block; the early
returns for `custom:`, cuts and `board` stay in `_render_segment`.
```python
def _segment_graph(project, group, seg_len, index, channel=None, chapter=None,
                   size=(WIDTH, HEIGHT), fps=FPS, dip_out=False
                   ) -> tuple[list[str], str, str]:
    """(ffmpeg input args, filter_complex, output label) for one photographic
    segment. Draws title/caption PNGs as a side effect; never runs ffmpeg."""
    ...
    return inputs, graph, last

# in _render_segment, after the early returns:
inputs, graph, last = _segment_graph(project, group, seg_len, index, channel,
                                     chapter, size, fps, dip_out)
ffutil.run([*inputs, "-filter_complex", graph, "-map", last, ...])  # unchanged
```
Traps inside the block:
- The parameter `frames` (a `(a, b)` tuple for drawn cuts) is **reassigned**
  to an int at ~line 568. Do not pass the tuple in; compute the int inside.
- `index` feeds `MOVES[index % len(MOVES)]`; pass it.
- It is not pure: `titles.render_caption/render_title/render_chapter` write
  PNGs, `_cover_crop` opens the image with Pillow, and the `stage` branch
  calls `shots_mod.ensure_clips` (a 3D render). Keep the side effects; the
  tests use `kenburns`/`essay` only, and PNG drawing is fast enough. If the
  test exceeds 2 s, monkeypatch `titles.render_*` to no-ops in the test.

**Goldens must be path-independent.** The graph and inputs contain absolute
paths. Normalise before comparing:
```python
def _norm(s: str) -> str:
    return s.replace(os.environ["CORKBORED_DATA"], "<DATA>").replace(str(ROOT), "<REPO>")
golden = "\n".join(_norm(a) for a in inputs) + "\n---\n" + _norm(graph).replace(";", ";\n")
```
Splitting the graph on `;` makes a failing diff readable (acceptance item 2).

**Proving "behaviour identical"** (step 4): before extracting, add a
temporary `log.info("ffmpeg %s", cmd)` and call `_render_segment` on the
fixture with `ffutil.run` monkeypatched to capture argv; do the same after;
assert equal. That is your real regression test; then delete the logging.

**`kit.place` test (step 7) caveat:** when a paragraph is crowded, `place`
scales all starts down to fit (`squeeze`), and after that holds can be
*shorter* than `min_hold`. Test the min-hold property on an uncrowded
input, and on a crowded input assert only monotonic starts, first = 0 and
`ends[-1] == length`. Do not "fix" `place`.

**SSIM (step 8-9).** `suite.ssim(a, b)` takes two image paths and resizes
to the suite's `TILE`; when moving it, make the tile size a parameter with
the old value as default. For the visual test, extract one frame with
`ffmpeg -ss 1 -i seg.mp4 -frames:v 1 x.png` and compare PNGs. The memory
note from the owner: independent encodes of identical frames land around
SSIM 0.998, so 0.99 is a sane threshold.
