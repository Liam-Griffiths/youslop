# T9.7 Script stage redesign
Phase 9 · Size M · Depends on: T9.3, T9.4
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
Each paragraph is a card with narration, on-screen title, visual note, words/time,
its check findings inline, and the existing rewrite/split/delete actions; keyboard
navigation between paragraphs, chapter dividers and a words-only check column.

## Why
The script editor is where most time is spent; today findings live on another tab.

## Read first
- `static/js/tabs/script.js` inside `static/js/shell.js`; `patch_slide`,
  `split_slide` in `app/main.py`; `app/check.py` (including `check.run`).
- `docs/design/mockups/Script.dc.html` in full and `docs/design/studio-flow.md` §7, 03 Script.

## Steps
1. Rebuild the paragraph row per the mockup; inline findings for that slide.
2. Keyboard: J/K or arrows to move, Enter to edit, Esc to leave.
3. Chapter breaks shown as dividers you can drag.

## Implementer notes
- Preserve existing controls, including stage visual revisions, sources,
  imports, shot list and chapter suggestions. Expose the existing T7.7 camera
  paragraph/presenter conversion controls in Script too.
- Words-only checks must not run the full visual/storyboard check or a model.
  Show supported deterministic text checks and researched claim flags; free-text
  channel rules remain writing guidance, not a claim of automatic validation.
- No merge action exists in the current Script editor or API; preserve Rewrite,
  Split and Delete rather than introducing a new take-merging operation here.
- Measure a 40-paragraph paint and record it; do not check on every keystroke.

## Acceptance
- All current script actions still work; findings show beside their paragraph.

## Verify
```sh
CORKBORED_DATA=$(mktemp -d) .venv/bin/python scripts/ui_snapshots.py --out /tmp/ui
```

## Don't
- Never drop recorded takes on edit (T4.9 rule).
