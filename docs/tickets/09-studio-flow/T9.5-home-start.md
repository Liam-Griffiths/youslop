# T9.5 Home and start-a-video flow
Phase 9 · Size M · Depends on: T9.3
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
Home shows recent projects as cards and a Start panel with five ways in (idea, own script, a footage shoot, a template/format, open a `.corkbored` file); choosing format and channel shows live preview stills; length target offers Short (vertical, under 60 s) and Long.

## Why
The first screen sets expectations. Today it is a form; the owner wants a flow.

## Read first
- `renderHome` and `newVideo` in app.js; `POST /api/projects` in main.py; `app/scenes.py` `capture` (preview stills); Phase 11 `footage` (start from a shoot).

## Steps
1. Recent projects grid (thumbnail, title, stage, last edited).
2. Start panel: idea | script | footage shoot (disabled until Phase 11, with a note) | template | open file.
3. Format picker shows a still per format rendered through `scenes.capture` or the existing preview, cached.
4. Length: Short (9:16, ≤60 s) or Long (minutes). Short sets the project aspect flag; renders that cannot do vertical yet show a clear "landscape only for now" note.
5. Channel picker with "new channel" inline.

## Acceptance
- A new project can be started each way that is enabled; nothing from the old New video page is lost.

## Don't
