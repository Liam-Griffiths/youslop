# T9.5 Home and start-a-video flow
Phase 9 · Size M · Depends on: T9.3
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
Home shows recent projects in a searchable table (Title, Channel, Stage, Length, Updated), with Footage shoots on the right, and a Start panel with five ways in (idea, own script, a footage shoot, a template/format, open a `.corkbored` file); choosing format and channel shows live preview stills; length target offers Short (vertical, under 60 s) and Long.

## Why
The first screen sets expectations. Today it is a form; the owner wants a flow.

## Read first
- `renderHome` and `createProject` in `static/js/tabs/home.js`; `static/js/shell.js`; `POST /api/projects` in `app/main.py`; `app/ops.py` `prepare_create`; `app/schema.py` `Project`; `app/store.py` `list_projects`; `app/stages.py`; `docs/design/studio-flow.md` §7 and `docs/design/mockups/Main.dc.html`; `app/scenes.py` `capture` (preview stills); Phase 11 `footage` (start from a shoot).

## Steps
1. Searchable projects table (Title, Channel, Stage + detail, Length, Updated), below the Start panel, with Footage shoots on the right. Include a cheap server-side stage summary in the list response.
2. Start panel: idea | script | footage shoot (disabled with a note until project/shoot integration is available) | template | open file.
3. Format picker uses the existing lightweight format previews and cached saved-style thumbnails; selecting a channel updates the preview accent. Keep video style cards and all existing secondary controls under More options.
4. Shape and length: Short (9:16, ≤60 s) or Long (minutes). Short sets the project aspect flag; renders that cannot do vertical yet show a clear "landscape only for now" note.
5. Channel picker with "new channel" inline.

## Acceptance
- A new project can be started each way that is enabled; nothing from the old New video page is lost.

## Verify
```sh
CORKBORED_DATA=$(mktemp -d) .venv/bin/python scripts/ui_snapshots.py --out /tmp/ui
```

## Don't
- Do not implement vertical rendering here; only the choice and the flag.

## Implementer notes
- Current home functions live in `static/js/tabs/home.js`, not app.js. Creation length is clamped in `ops.prepare_create`; adjust that clamp for Short.
- T11.1–T11.4 provide `app/footage.py` storage and CLI operations plus an export page, but no shoots JSON list or project/shoot creation link. A read-only summary endpoint is small; keep starting/importing shoots disabled until that integration lands.
- Mockup layout supersedes the original cards step. Project aspect is a scalar defaulting to landscape and must be explicitly serialized. No vertical render is added.
