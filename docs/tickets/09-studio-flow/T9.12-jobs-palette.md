# T9.12 Jobs centre and command palette
Phase 9 · Size S · Depends on: T9.3
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
A jobs drawer lists every running and recent job (render, research, voice, proxies, labelling) with progress and cancel; Ctrl+K opens a command palette of actions and routes.

## Why
Background work (proxies, labelling, renders) grows with Phase 11; it needs one place.

## Read first
- `app/jobs.py`, jobs endpoints in `app/main.py`, `watchJob` in
  `static/js/core.js`, `paintJobsStrip` in `static/js/shell.js`.

## Steps
1. Add `GET /api/jobs` summaries across all projects and a drawer opened by the
   strip. Poll summaries only while the drawer is open; Escape closes and returns
   focus. Preserve `watchJob` behavior. Add cooperative opt-in cancellation via
   `jobs.start(..., cancellable=False)` and `POST /api/jobs/{jid}/cancel` (409
   for unsupported/finished jobs). A cancellation flag makes the next `progress`
   raise `JobCancelled`; finish as `cancelled` without a traceback.
   Opt in only timeline proxy/sound, segment preview, snapshot, footage,
   library-scan, research, headlines and description. These operations may already
   write regenerable caches incrementally; cancellation keeps completed artifacts.
   Never opt in voice, recordings, camera, final render or uploads.
2. Palette: fuzzy match over a global command registry in `static/js/palette.js`.
   Ctrl/Cmd+K and a top-bar hint open an accessible dialog with combobox/listbox,
   arrows, Enter and Escape. Register app routes, the six stages when a project is
   open, new project, current-section preview and jobs. No full-render action.
   Load new scripts before shell.js (second-to-last), with boot.js last.

## Acceptance
- Jobs from two projects show at once; palette opens every stage and runs common actions.

## Verify
```sh
.venv/bin/pytest tests/unit -q
```

## Don't
- No new job types here.

## Implementer notes

  not dialog actions.
- Add fast synthetic tests for summaries and cancellation; no real work or LLMs.
