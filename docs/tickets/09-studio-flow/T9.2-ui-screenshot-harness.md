# T9.2 UI screenshot and console harness
Phase 9 · Size S · Depends on: T0.5
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
`scripts/ui_snapshots.py` starts the app on a temporary data root seeded with a fixture project, visits every route through CDP (`app/stage.py`), saves a PNG per route plus a contact sheet, and fails on any console error.

## Why
Every Phase 9 ticket changes screens. Headless screenshots caught real bugs during the 2026-10-31 run (a leftover "R" mark, overlay labels hiding titles); making that one command lets an implementer without a browser check their own work.

## Read first
- `app/stage.py`: `_run_cdp`, `capture_one` (CDP pipe, no Node).
- `tests/_fixtures.py` (`load_project`), `scripts/check_review.py` (temp data-root pattern).
- `static/js/core.js` `route()` and `render()` for the current route list.

## Steps
1. Seed a temp data root: one fixture project per format family (kenburns, essay, a drawn cut, stage), one channel, one library item.
2. Start uvicorn on a free port in-process (thread) with `CORKBORED_TOKEN=off`.
3. For each route in a list kept next to the script (home, library, settings, guide, each existing project tab, channel videos/setup; extend as Phase 9 adds screens), navigate, wait for `document.fonts.ready` and network idle, capture 1600×1000 PNG, collect `Runtime.consoleAPICalled` errors and `Runtime.exceptionThrown`. Current project tabs are script/media/record/thumb/render, plus cast/stage for stage projects; the six new stages do not exist yet.
4. Write `ui-snapshots/<route>.png` and `sheet.png` (labels under frames, as `review.sheet` does).
5. Exit non-zero on any console error or exception; print them.
6. Optional `--compare <dir>`: SSIM per route against a previous run, list changed routes.

## Acceptance
- One command produces a PNG per route and a contact sheet in under 60 s.
- A deliberate `console.error` in `static/js/core.js` makes it exit 1.

## Verify
Pure checks (no Chromium or sockets):
```sh
CORKBORED_DATA=$(mktemp -d) .venv/bin/pytest tests/unit/test_ui_snapshots.py tests/unit/test_cdp_framing.py -q
```
Browser check is **reviewer-run**: Chromium and loopback sockets are unavailable
in the implementer's sandbox. Review the PNGs/sheet and the under-60-second
budget, then temporarily inject `console.error('harness probe')` in
`static/js/core.js` and confirm exit 1 (restore the file afterwards).
```sh
CORKBORED_DATA=$(mktemp -d) .venv/bin/python scripts/ui_snapshots.py --out /tmp/ui
```

## Don't
- No Playwright, no Node. CDP over the pipe only.
- Never point it at the owner's real data root.
