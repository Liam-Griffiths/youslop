# T9.6 Plan stage: sources and the outline in chapter columns
Phase 9 · Size M · Depends on: T9.3, T9.4
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
The Plan stage shows research sources and the outline as plain cards in chapter columns (Instrument style; no cork texture): chapters as columns, beats as notes that can be dragged to reorder or move between chapters, sources pinned to the beats they support; edits save to the existing outline/script fields.

## Why
Seeing chapters side by side, with sources attached to beats, is how people actually plan a video. The board idea stays in the structure, not the styling: the owner wants a serious app.

## Read first
- Outline and research data in `app/schema.py` (`Project.outline`, sources), `app/script_gen.py`, `app/research.py`; `app/edits.py` (slide edits only).
- Approved layout: `docs/design/mockups/Plan.dc.html`; rules: `docs/design/studio-flow.md` §7, “02 Plan”.
- Shell and script loading: `static/js/shell.js` (`stageTab`), `static/js/core.js` (`render`), `static/index.html`, `tests/unit/test_js_globals.py`.

## Steps
1. Give Plan its own `static/js/tabs/plan.js` view and shell route, following `docs/design/mockups/Plan.dc.html` and studio-flow §7. Existing outline `sections` are beats; optional chapter labels group them into columns. Research facts supply source title/URL metadata. Preserve draft outlines.
2. Drag to reorder (pointer events, no library); keyboard alternative (Alt+arrows).
3. Source cards with title/URL; drag onto a beat to cite it.
4. "Write the script from this board" uses the existing section writer for changed beats only via a board mode on the script endpoint. Keep unchanged slides/takes; retire replaced takes into history. Store board metadata in the existing outline dict and add a small save endpoint (edits.py only handles slide fields).

## Acceptance
- Reordering on the board changes paragraph order after regeneration; citations persist.
