# T9.10 Edit stage: the Timeline workspace
Phase 9 · Size M · Depends on: T9.3, T4.3
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
The Timeline becomes a full-width workspace (preview, layers, inspector on the right), hosting the Phase 4 editor features and the sponsor lane from Phase 10.

## Why
Phase 4 builds editor features into today's Render tab; the new flow gives them their own stage.

## Read first
- `static/js/timeline/*.js`, `static/js/tabs/render.js` (`paintEdit`),
  `static/js/shell.js`, `static/styles.css`; Phase 4 tickets T4.3–T4.8, T10.6.
- `docs/design/mockups/Edit.dc.html` (layout) and `docs/design/studio-flow.md` §7 "07 Edit" (rules).

## Steps
1. Move the Timeline into the Edit stage at full width; inspector uses the shell's right slot.
2. Keep keyboard shortcuts; add a shortcut sheet (?).
3. Leave render/publish controls to the Review & publish stage.

## Acceptance
- Everything Phase 4 has delivered works in the new stage; the preview size adapts to window width.

## Verify
```sh
CORKBORED_DATA=$(mktemp -d) .venv/bin/python scripts/ui_snapshots.py --out /tmp/ui
```

## Don't
- Do not implement Phase 4 features here; host them.

## Implementer notes
- Edit already has a route and `paintEdit` mounts `tlMount`; this ticket widens
  that workspace rather than moving it out of Render again.
- Reuse the shell's `#inspector` element beside the player; return it to the
  shell before route changes or project repaints so it is never discarded.
- Keep all existing lanes (including cues, stings and camera source edits).
  Essay caption spans already arrive in the titles layer: display them in a
  Captions lane, retaining the title inspector and shared visibility flag.
  Other formats have no separate caption-span API; do not invent timing here.
- Replace the old batch "draw all" UI with explicit single-segment preview;
  opening Edit must not draw pictures. Render/publish stay in their stage.
