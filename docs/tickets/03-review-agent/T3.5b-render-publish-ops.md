   T0.8 note constant; the renderer computes its budget dynamically).

4. Extend `_operation` HTTP routing and job polling. Keep slow work synchronous
   with the app closed. Update the producer skill with the actual commands.
5. Add fast mocked tests for both modes, full-render refusal, validation errors
   and original-vs-refactored HTTP response parity. No real uploads or LLMs.
