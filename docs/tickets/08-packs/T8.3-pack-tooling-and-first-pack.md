# T8.3 Pack tooling, the open format spec and the first free pack
Phase 8 · Size S · Depends on: T8.1, T8.2, T0.7

## Goal
Anyone can make a pack: a written spec (`docs/packs.md`), a CLI command that
checks and builds one, and a first free pack, made by the owner, that proves
the format end to end and shows what a pack is for.

## Why
A pack format nobody else can use is just a folder. Publishing the spec and
the builder invites free community packs, which make Corkbored more useful and
make the paid packs easier to understand.

## Read first
- T8.1 (format), T8.2 (install).
- `app/cli.py` (T0.7): command layout.
- `docs/tickets/02-scene-engine/T2.2-scene-runtime.md`: the scene contract,
  which the spec links to rather than repeats.

## Steps
1. **`docs/packs.md`:** the folder layout and `pack.json` fields from T8.1;
   what each kind is for; the scene contract (link); what is forbidden (no
   Python, no network, no executables); how credits and licences work; how
   to test a pack locally; how to build it. Plain language, with one
   complete small example.
2. **CLI.** `corkbored pack check <folder>` prints T8.1's problems (exit code
   1 if any) plus a lint of every scene template and a one-frame preview of
   each to `<folder>/.check/` (480x270, via `scenes.capture`).
   `corkbored pack build <folder>` runs check, then writes
   `<id>-<version>.corkboredpack`, excluding `.check/` and dotfiles.
3. **Licence for scene templates.** Pack scene templates use
   `static/scene/runtime.js` and extend `_base.html` (T2.2, T2.3), which are
   part of the GPL app. Put those two files, plus `_base.css`, under the MIT
   licence with a header comment in each and a line in `THIRD-PARTY.md`, so
   a pack author (the owner included) can license their templates as they
   choose. **Owner decision needed:** this is open in NOTES.md. Ask before
   doing this step; if the answer is no, pack templates are GPL like the
   app, and the spec says so.
4. **The first free pack: "Starter".** One theme, three scene templates
   (cold open, chapter card, end card), two CC0 music beds, no models. Built
   by the owner with the implementer; ship it in the repo under
   `packs/starter/` (resource root, so it is built in and cannot be removed).
   Every item's licence is CC0 or the owner's own.
5. **Tests:** `pack check` on the fixture pack passes; on a pack with a
   `.py` file fails with a clear message; `pack build` output installs
   through T8.2's path.

## Acceptance
- Following only `docs/packs.md`, a new pack with one theme and one scene
  can be made, checked, built and installed.
- The Starter pack appears in a fresh install and its three templates
  render.

## Verify
```sh
.venv/bin/pytest tests/unit/test_pack_cli.py -q
.venv/bin/python -m app.cli pack check packs/starter
```

## Don't
- Do not move built-in themes or templates into packs in this ticket.
- No pack hosting, index or update checks.

## Implementer notes
*Written 2026-10-26.*

- Music in the Starter pack must be CC0 with the source URL recorded in
  `credits.json`; if suitable CC0 beds cannot be found quickly, ship the
  pack without music and log it, rather than using anything with
  attribution or non-commercial terms.
- Step 3 changes the licence of three files. Only the copyright holder can
  do that, so it is the owner's call; check NOTES.md for the answer. If
  there is none, ask. Never extend it to any other file.
