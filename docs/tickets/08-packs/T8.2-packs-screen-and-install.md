# T8.2 Packs screen and install from a file
Phase 8 · Size S · Depends on: T8.1, T6.1

## Goal
Settings gains a **Packs** screen: installed packs with their preview,
contents, licence and version; "Install pack…" takes a `.corkboredpack` file
(a zip); a pack can be removed, and the app says which channels and
projects use it before it goes.

## Why
Buying or downloading a pack must end in two clicks, with no terminal and no
hunting for the data folder.

## Read first
- T8.1 `app/packs.py`.
- `app/transfer.py`: how project bundles are unpacked safely (`EXTENSION`,
  the manifest key); reuse its zip handling.
- `app/models3d.py` `add()`: the upload pattern for a single file.
- The Settings tab in `static/js/` and its existing sections.

## Steps
1. **Package format.** `.corkboredpack` is a zip whose top level is one
   folder named after the pack id, containing `pack.json`.
2. **Install.** `POST /api/packs/install` (multipart). Unzip into a temp
   folder under `<data>/.cache/`, reject zip-slip paths, symlinks, anything
   T8.1 calls broken, and archives over 2 GB unpacked. Then validate with
   `packs._validate`. If the id already exists:
   - same or older version: say so and stop;
   - newer version: move the old folder to `<data>/packs/.old/<id>-<version>/`
     (kept, not deleted), then move the new one into place.
   Rescan. Return the pack summary.
3. **Remove.** `GET /api/packs/{id}/uses` lists channels (theme, intro,
   outro, thumbnail template) and projects (music, scenes, cast models) that
   refer to `<id>/…`. The UI shows that list, then "Remove" moves the folder
   to `<data>/packs/.old/` as above. Projects that used it fall back as T8.1
   describes and say so in the check (T1.5) if that has landed.
4. **Screen.** Settings → Packs: a card per pack (preview image, name,
   author, version, item counts by kind, licence link), "Show contents"
   expanding to the item list, and broken packs shown with their problems.
   An "Get more packs" link points at a URL from `app/brand.py` (T0.1), left
   empty until there is somewhere to send people.
5. **Desktop.** Opening a `.corkboredpack` file from the file manager is out
   of scope; dragging one onto the window installs it (the same drop
   handler as project bundles, routed by extension).
6. **Tests:** install, reinstall the same version (refused), upgrade (old
   kept under `.old`), zip-slip refused, uses list for a channel and a
   project.

## Acceptance
- Dragging the demo pack zipped as `.corkboredpack` onto the app installs it
  and its items appear in the pickers without a restart.
- Removing it lists the one channel that uses its theme first, and the old
  folder is still on disk under `packs/.old/`.

## Verify
```sh
.venv/bin/pytest tests/unit/test_packs_install.py -q
```

## Don't
- No store, accounts, licence keys or download-on-demand. Paid packs are
  sold outside the app and installed from the file.
- Never delete a pack folder; "remove" moves it aside.

## Implementer notes
*Written 2026-10-26.*

- `transfer.py` already solves "unzip a user's file safely"; read it before
  writing new zip code and share a helper rather than copying it.
- The uses query is a scan over channel and project JSON for strings
  starting with `"<id>/"`. That is crude and good enough; do not add an
  index.
- Card copy in the Corkbored voice (T6.3): "Signal Essays · 1.0.0 · Liam
  Griffiths · 2 themes, 6 scenes, 4 tracks".
