# T13.5 Drawn-cut pieces as blocks (pilot: Group Chat)
Phase 13 · Size M · Depends on: T13.1, T12.13 batch D · **Later: not in the current queue; owner schedules it**
*Written 2026-11-08 (Claude Opus 5.5) from the owner's style rethink.*

## Goal
The pieces of one drawn cut (Group Chat's message thread, cutaway and reaction) exist as blocks that any video can use. The Group Chat kit is built from those blocks, without its own renderer, and looks the same.

## Why
Once styles are kits (T13.3) and kinds mix (T13.1), the drawn cuts are the last part that only one style can use. Turning their pieces into our own sandbox-clean blocks also settles the "Duplicate as mine" problem (T12.8c) for these pieces.

## Read first
- `app/cuts/groupchat.py`, `app/cuts/groupchat_scene.py`, `app/cuts/kit.py`.
- T12.13 batch D `chat_thread`, and `docs/blocks/format.md`.

## Steps
1. List Group Chat's visual pieces and the cue fields each one reads.
2. Build the pieces as blocks: shared tokens, overlay where it fits, and they pass the sandbox, so "Duplicate as mine" works.
3. Write an adapter so a Group Chat paragraph's cues render through those blocks. Compare midpoint frames against the current renderer for three fixture paragraphs (SSIM ≥ 0.95, or the reviewer judges the differences).
4. Report what the other four cuts would need. Don't port them here.

## Acceptance
- The three fixture paragraphs match within tolerance.
- The blocks pass `block check` and the sandbox.
- The old renderer path remains as a fallback behind a flag.

## Don't
- Don't port the other cuts. Don't delete `app/cuts/groupchat*.py`.
