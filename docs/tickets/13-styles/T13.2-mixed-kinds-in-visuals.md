# T13.2 Visuals: choose each paragraph's kind of picture
Phase 13 · Size M · Depends on: T13.1, T9.8
*Written 2026-11-08 (Claude Opus 5.5) from the owner's style rethink.*

## Goal
In Visuals, each paragraph (or picture group) shows its kind and has a "Kind" control. It can be the style default or any other kind. The source panel, editors and mix bar adapt for each paragraph.

## Why
T13.1 makes mixed kinds render. This makes them usable. Owner, 2026-11-08: "yes mix kinds".

## Read first
- T13.1's Log (`kind_for`, the audit table, the join rule).
- `static/js/tabs/media.js` (Visuals groups, the source panel per format, `boardKnobs`, `cutKnobs`, the cue editor, `planCues`), `static/js/timeline/*.js` (inspector), `app/stages.py` (mix bar).
- `docs/design/studio-flow.md` §8 "Visuals by format" and the segmented control and inspector rows.

## Steps
1. **Kind control.** Each picture group's header shows a compact kind chip ("Documentary photo", "Board", "Casefile", "Block: Title card", …). Clicking it opens a menu: "Style default (X)", then the kinds grouped as Pictures (Documentary photo, Essay slide), Drawn (Board, Flameboat, Casefile, Loudmouth, Group Chat, Ticker), 3D, Your styles and Block…. Choosing "Block…" opens the existing block picker. A selected range of paragraphs can be set at once.
2. **Source panel per paragraph.** The source panel and editors follow the selected paragraph's resolved kind, not the project format: the board editor for a board paragraph, the cue editor for a cut paragraph, and the archive, library and footage tabs for photo kinds. Knobs that are global to a kind (board hand, cut look) are still edited once per project, under "Kind settings", which lists only kinds present in the video.
3. **Planning buttons.** "Plan board" and "Plan cues" appear when the video contains that kind, and act only on those paragraphs (T13.1 step 4).
4. **Mix bar.** It counts by resolved kind and gives each kind a legend colour drawn from existing tokens. A paragraph that is missing what its kind needs (cues, board text, a picture) shows the per-paragraph finding inline.
5. **Timeline.** The Edit stage inspector shows the kind for the selected paragraph, with the same menu.
6. **Snapshots.** Add a fixture project with mixed kinds to `ui_snapshots.py` (Visuals and Edit).

## Acceptance
- In headless Chromium, in the mixed fixture project:
  - setting paragraph 2 to Board shows the board editor for it and the photo picker for paragraph 1;
  - the mix bar counts change;
  - reloading keeps the choice;
  - setting it back to "Style default" keeps its board text (verified through the API).
- 0 console errors, and existing single-kind Visuals snapshots look unchanged apart from the new chip.
