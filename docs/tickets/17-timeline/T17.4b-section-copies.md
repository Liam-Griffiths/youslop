# T17.4b Copy, cut, paste and duplicate sections
Phase 17 · Size M · Depends on: T17.4

## Goal
Copy sections with their inserts and attached items, and paste at the playhead
or duplicate immediately after the source. Cut removes only project metadata.

## Read first
- `app/sections.py`, `app/undo.py` (`retain_recordings`), `app/schema.py`
- `static/js/timeline/sections.js`, `static/js/tabs/script.js`
- `docs/tickets/17-timeline/T17.4-reorder.md`

## Steps
1. Extend the sections API with copy. Validate the source version under the
   lock. Copy returns a detached snapshot without saving; Paste and Duplicate
   allocate fresh row/graphic/sponsor ids and remap paragraph anchors.
   Copies include all insert kinds, pictures, narration, titles, cues,
   graphics, chapters and sponsor slots. Keep picture-group fragments intact.
2. Reference existing media and take paths; never create, copy, modify or
   delete audio files. Mark duplicated narrated paragraphs in the script view
   with a backward-compatible field.
3. Add Cut, Copy, Paste and Duplicate to the section toolbar and shortcuts
   Ctrl/Cmd+X/C/V/D. Keep a detached clipboard snapshot. Paste at the boundary
   nearest the playhead; Duplicate places the copy after the original.
   Cut and each paste/duplicate publish once with an explicit undo label.
4. Audit shared take safety across deletion, retakes, reprocessing, project
   cleanup/import replacement, failed split cleanup, orphan sweeps and undo
   pruning. Preserve files referenced by slides, sponsors, take history,
   retired takes or undo checkpoints. Re-recording retires only that owner's
   reference. Add synthetic regression tests for these paths.

## Acceptance
- Copies include inserts and attached items; later items ripple by the length.
- Each content operation undoes exactly once, restoring the prior project.
- No media or take file changes; source and duplicate remain independently editable.

## Implementer notes
- API: `POST /api/projects/{pid}/sections` accepts `copy|cut|duplicate` with
  `{ids, version}`, and `paste` with `{clipboard, to, version}`. Existing
  `move|delete` payloads remain supported. `to` is a row id or `""` for the
  end; Paste uses the destination's current version. Copy/Cut return
  `section_clipboard`; Copy never saves. Paths are project-relative, so the
  detached clipboard is restricted to its source project.
- `Slide.duplicate_of` defaults to `""` on old projects. It marks copied
  narrated paragraphs and does not affect render/proxy cache signatures.
- Copies pin included sponsor reads to their copied paragraph. Original
  pre/end placement rules remain unchanged during Copy/Paste/Duplicate;
  Cut removes the included reads with their source rows.
- Shared-audio audit found destructive project deletion/import replacement,
  in-place mic reprocessing, legacy presenter cleanup (potential camera raw
  sources), and failed-split cleanup that could unlink a published take.
  Project archiving was reverted in review; deletion/import replacement keep
  their existing behaviour pending an owner decision. Reprocess to fresh
  paths; retain presenter sources; protect live and undo-checkpoint files
  during split failure cleanup. No take/audio orphan sweep exists; renderer
  sweeps only segment scratch. Undo pruning removes compressed metadata,
  never recordings; recording retention now also applies to untracked saves.
- `scripts/ui_snapshots.py` adds synthetic `section-copy` and `section-paste`
  captures and an exact undo check. Browser execution and visual judgement
  are reviewer-run, as in T17.4. No segment preview is required.
- Review correction to T17.4 gestures: plain ruler and unselected main-track
  item drags scrub live. Shift+drag on the ruler or pictures selects a range;
  only dragging inside an already-selected section moves it. The playhead's
  ruler handle always scrubs. Plain item clicks still select and seek.
