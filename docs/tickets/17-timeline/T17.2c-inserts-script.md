## Steps
1. Test and implement preservation of insert ids/metadata/order during whole
   script generation/import. Define how a replaced or removed paragraph anchor
   maps onto the new script, including intro, consecutive and terminal inserts
   and a replacement with fewer paragraphs. Keep the single Project.slides list.
2. Keep recorded takes/history reachable through replacement and persistence;
   never overwrite/delete recordings. Preserve existing paragraph-edit behavior
   and test failure paths before removing the explicit T17.2c guards.
3. Exclude inserts from narration planning, rewriting, consistency and research
   verification, TTS, automatic media selection and word-based findings. Test
   the actual entry points using mocked models/engines, never a real model.
4. Adjust stages/counts where needed: inserts are pictures, not unwritten or
   unread paragraphs. Preserve legacy project/storyboard/key bytes.
5. Remove whole-script replacement guards only once preservation tests pass.

## Acceptance
- Generation/import keep all inserts and all recorded takes reachable.
- Narration operations never send inserts to a model or voice engine.
- Script/Voice counts exclude inserts; Visuals includes their main-track rows.
- All legacy goldens and segment/proxy/mix keys remain unchanged.
