# T17.5 Extend and shrink: picture tails, insert lengths, clip trims
Phase 17 · Size M · Depends on: T17.2, T17.1

## Goal
Drag the edge of a main-track item to make it longer or shorter, with ripple
by default and a roll edit on demand.

## Read first
- T4.5 and T4.2 (retime fields: gap, holds), `edit.js` `tlSnap` and
  `tlGapItems`, T14.4 `clip_projects.update` (word trims), T17.2 insert fields.

## Steps
1. Right edge of a narrated paragraph's picture: extends the hold after the
   last word (the existing gap or tail field). It can't shrink into speech;
   below the spoken end it stops, with a hint to use the razor (T4.6).
2. Inserts: both edges. A held picture, block or card changes length; a clip
   changes its source in/out (a trim). Alt+drag inside a clip slips the
   source range without changing its length.
3. Ripple by default: later items move. Holding Shift (or the toolbar's
   Ripple/Roll toggle) does a roll edit instead: the neighbour gives or takes
   the same time, and the total stays the same.
4. Snapping: word edges, frames, the playhead and other edit points (`tlSnap`
   extended), with Alt to disable as now. Show the new length live while
   dragging ("4.20 s, +0.80").
5. Keyboard: `[` and `]` trim the selected item's start or end to the
   playhead. Shift+`[` and Shift+`]` nudge one frame.

## Acceptance
- Extending a picture by 1 s moves every later item by 1 s, and a roll edit
  keeps the total length.
- Speech is never cut by a trim.
- Clip trims never modify the source file.

## Implementer notes

2026-11-11: Pictures can span several narrated paragraphs: their right edge
changes the final paragraph's `gap_override` (0–10 s), never a take. Inserts
are individual main-track rows. A roll borrows only available silence from a
narrated neighbour, or length/source range from an insert; it stops at speech,
source bounds, sponsors or the end of the main track. Narrated starts cannot
be trimmed. Source-linked clip projects retain their existing word-trim UI.
Use one atomic metadata save for both sides of a roll. `[` / `]` take priority
for a selected main-track item; other lane selections retain item navigation.
Shift+`[` shrinks from the start by one frame; Shift+`]` extends the end by
one frame. Alt inside a clip insert slips; Alt at an edge disables snapping.
Keep handles 6 px wide on Pictures only; leave gap handles and + buttons intact.
