# T4.4 Layers rows
Phase 4 · Size M · Depends on: T4.3, T0.7

## Goal
Under the picture strip the Timeline draws rows for titles, cues, chapters,
music and stings, each item at its real time, each clickable to select, each
row with an eye toggle that hides it from the preview.

## Why
The editor cannot show what it cannot draw. All the times exist already in
`render.timeline()` after T4.2; cue times come from `kit.place`.

## Read first
- `static/js/timeline/draw.js`: `tlDraw` ~221, `tlPaintHead`, `tlPaintProblems`,
  `tlRate`, `tlStepFor(zoom)`, `tlThumb`; the canvas or DOM approach used
  (check whether rows are canvas or elements; follow it).
- `render.timeline()`: add per-paragraph `cues: [{at, text, kind}]` from
  `kit.place` (pure, cheap) if T4.2 did not already; titles, chapters, and
  the music/sting spans from `_audio_graph` inputs (expose the plan, not
  the graph).
- `app/storyboard.py` `build` (same data, for the CLI).
- `TL.selection` (T4.3).

## Steps
1. `render.timeline()` returns `layers: {titles:[], cues:[], chapters:[],
   music:[], stings:[]}` each item `{id, sid, t0, t1, text, kind, src}` in
   absolute seconds. One helper `_layers(project, segs)`; unit-test it.
2. `static/js/timeline/layers.js` (new; add to `index.html`): draw five rows
   under the strip, 22 px each, labels in 11 px uppercase on the left,
   items as rounded 4 px bars with text clipped; selected item gets the
   accent outline; hover shows a tooltip with time and text. Scrolls and
   zooms with the strip (reuse `tlStepFor`).
3. Eye toggles per row stored in `TL.hidden = {titles:false, ...}`. Hidden
   layers are passed as `?hide=titles,cues` to the proxy build
   (`proxy_segment` gains `hide: set[str]`; `_render_segment` skips those
   overlays when preview and hidden). Proxies are keyed on it
   (`_proxy_key` includes `hide`).
4. Clicking an item: `tlSelect({kind, id, sid, t0, t1})` and the inspector
   (T4.3) updates. Double-click seeks the playhead to `t0`.
5. The Check/Review markers (T1.6, T3.2) move into a sixth row `notes` with
   severity colours, so problems and layers share one ruler.

## Acceptance
- On the test project all titles, cues and chapters appear at the right
  times (spot-check three against the proxy); hiding `cues` and replaying
  shows no cue overlays.

## Verify
```sh
.venv/bin/pytest tests/unit/test_layers.py -q
```

## Don't
- Do not compute layer times in JS; the server is the single source.
- Hidden layers affect previews only, never the final render.

## Implementer notes
*Added 2026-10-26.*

- The Timeline is **DOM, not canvas**: `tlDraw()` (timeline.js ~221)
  builds lanes as `<div class="tl-lane">` with absolutely positioned items
  at `left: t * TL.zoom px`. Add the five rows the same way inside the same
  `track.innerHTML` template, so they scroll and zoom with no extra code.
  Label with the existing `<em>` lane label pattern.
- Cue absolute times: use `cuts.timed_cues` (T0.7) plus the segment start
  from `timeline()`; storyboard already does this, so `_layers()` can be
  built from `storyboard.build(project)` rather than recomputing. Watch
  for the recursion trap from T1.6 (do not call `storyboard.build` from
  inside `timeline()`); build layers in the endpoint, or have `storyboard`
  expose a helper that takes an existing `tl`.
- Titles' absolute times: the title timing formula lives in
  `_segment_graph` (T0.5/T1.4). Factor it into
  `_title_window(frame, slide, offset, dur) -> (start, end)` and call it
  from both, or the layer row and the pixels will disagree.
- Music and stings: `_stings_for(project)` (render.py ~1801) and
  `_layout(project)` already compute the slate and sting spans; read them
  instead of parsing the audio graph.
- `hide` for proxies: thread a `hide: frozenset = frozenset()` argument
  through `proxy_segment` → `_build_proxy` → `_render_segment` →
  `_segment_graph`, include `sorted(hide)` in `_proxy_key`, and store
  hidden variants under a different filename (append `_h<hash>`), so
  un-hiding does not need a re-render.
