# T6.2 Mark, favicon and app icon
Phase 6 · Size S · Depends on: T0.4

## Goal
The cork / post-it logo (drawn 2026-10-31, `docs/brand/`) is wired in
everywhere: favicon, app icon (all platform sizes), the header lockup, the
about screen and any slate that shows the product mark.

## Why
The 🪣 emoji is the current mark in `index.html` (favicon line 9, header
line 18). A serious name needs a mark that reads at 16 px and 512 px from
the same drawing.

## Read first
- `scripts/make_icon.py`: how the current icon is produced and where it is
  written (PyInstaller spec references).
- `app/intro.py`: drawing primitives (grep `rounded_rectangle`, `line`,
  stroke helpers) to reuse; or `app/titles.py` if simpler.
- `static/index.html` lines 9 and 18; the `.mark` and `.drip` CSS in
  `styles.css` (remove `.drip`).
- `app/brand.py` (T0.1): `NAME`, `LONG_NAME`.
- `static/landing.html`: the wordmark as the public sees it (condensed
  Archivo 800, uppercase, tight tracking, no badge). The
  app header wordmark should read as the same brand. It uses
  `var(--display)`, so it follows whichever face the T6.1 switch has selected.

## Steps
*Rewritten 2026-10-31: the owner chose a new logo — a yellow sticky note with a
black play mark, pinned with an orange push pin on cork. The drawing exists;
this ticket wires it in. The earlier Pillow push-pin-card plan is dropped.*

Source of truth: `docs/brand/src/build.py` (regenerates every file below) and
the hand-edited `docs/brand/src/corkbored-icon.svg`.

| File | Use |
|---|---|
| `docs/brand/corkbored-icon.svg` / `-1024.png` / `-256.png` | app icon: textured cork tile |
| `docs/brand/corkbored-mark.svg` / `-64.png` | favicon and anything under ~64 px: flat cork chip, no texture |
| `docs/brand/corkbored-header.svg` | app header lockup (mark + wordmark, light text for the dark bar) |
| `docs/brand/corkbored-light.svg` / `-dark.svg` | README and docs lockups |
| `docs/brand/corkbored-banner.svg` / `.png` | README hero / social card |
| `static/brand/*` | copies the app and scenes load |

1. `scripts/make_icon.py`: rasterise `corkbored-icon.svg` with headless
   Chromium (the `render()` helper in `build.py`; Pillow cannot read SVG) at
   1024 and downscale with `Image.LANCZOS` for the iconset; at 16 and 32 px use
   `corkbored-mark.svg` instead (texture turns to noise). Write `.icns`, `.ico`
   (16/32/48/256) and `resources/icon_1024.png`.
2. `static/index.html`: favicon `href="/static/brand/corkbored-mark.svg"`;
   header shows the mark (inline SVG or `<img>`) + the wordmark in
   `var(--display)` (or the header lockup SVG if the display-face switch is on
   Archivo Black). Remove the temporary "C" letter mark and the `.drip` CSS.
3. About screen / `#/guide` header uses the 128 px icon.
4. README draft: banner at the top (`docs/brand/corkbored-banner.png`),
   lockups via `<picture>` light/dark.
5. Test: `make_icon.py` produces every size; the favicon URL resolves; the
   header contains no single-letter mark.

## Acceptance
- Browser tab, desktop window, Linux launcher and header all show the post-it
  mark; at 16 px it reads as a yellow note with a play mark on cork.
