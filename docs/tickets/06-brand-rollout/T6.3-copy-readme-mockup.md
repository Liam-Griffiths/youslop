# T6.3 Copy, README and mockup
Phase 6 · Size S · Depends on: T6.1, T6.2

## Goal
All user-facing copy speaks in the Corkbored voice, the README leads with a
two-sentence manifesto and a short History note about Youslop, and the
scene-engine cards become the default choice for new channels where they
exist.

## Why
Brand is mostly words. The mockup page approved earlier (plan §2) is what the
app should now match; this ticket closes the gap and decides the default
engine per surface.

## Read first
- `README.md`, `README-BUILD.md`, `THIRD-PARTY.md`, `docs/roadmap.md` §1–2.
- `static/landing.html`: the approved public copy and tone ("Idea in.
  Episode out.", the production-log narrative). README and in-app copy
  should match its voice.
- `static/js/tabs/guide.js` (was `renderGuide` ~393 in `app.js`): the in-app
  guide copy.
- Every `tlMsg(` / toast / empty-state string in `static/js/**` (grep for
  `!` inside string literals and for the words "slop", "oops", "yay").
- `app/channels.py` / channel defaults: where intro and outro templates
  default (T2.5/T2.6 registered `scene:` keys).
- `.env.example`, `docker-compose*.yml` names (T0.4 renamed; confirm).

## Steps
1. Copy pass: plain, confident, short sentences; no exclamation marks; no
   jokes in the chrome. Rewrite the guide, empty states, toasts and button
   labels. Keep a short list of changed strings in the Log for review.
2. `README.md`: **start from `docs/readme-draft.md`** (written 2026-10-26,
   modelled on the HyperFrames and EffectCraft READMEs; its header comment
   lists what to fill in: screenshots, channel link, release file names, the
   Status table checked against PROGRESS.md). Move it into place, delete the
   draft. The rest of this step describes what it must still contain: title "Corkbored"; two-sentence manifesto (careful, researched
   long-form video, cheap to make, on your own machine); what it does in
   six bullets (research, write, narrate, cut, review, publish); requirements
   (Python, ffmpeg, Chromium; no Node); quick start; a "History" section of
   three sentences about Youslop; links to `docs/roadmap.md` and the skill.
   Tagline is "Idea in. Episode out." (used on the landing page).
3. Defaults: new channels default to `scene:intro_solo`, `scene:outro_twoup`
   and the scene chapter card where Chromium is available
   (`stage.browser()` truthy); otherwise the Pillow equivalents, with a
   settings note saying which engine drew the preview.
4. Mockup reconciliation: open the approved mockup and the app side by side
   on home, Script, Render (Timeline + Check) and Settings; list the
   remaining differences in the Log and fix the cheap ones here; file the
   rest as new tickets under `06-brand-rollout/`.
5. Final rename sweep: `grep -rniI 'youslop' --exclude-dir=.venv --exclude-dir=.git .`
   lists only the compatibility shims (`brand.py` legacy prefixes,
   `paths.py` legacy dir, `transfer.py` legacy key/extension) and the README
   History section. Fix anything else.

6. Decide whether `static/landing.html` is served by the app (e.g. at
   `/landing`) or hosted elsewhere; if served, switch its fonts to `/fonts`
   (T6.1 does this) and remove the Google Fonts link.

## Acceptance
- A new user reading README.md knows what Corkbored does and how to run it in
  under a minute; the app has no exclamation marks in its chrome.
