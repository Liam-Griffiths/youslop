# T11.7 Shot list from the script
Phase 11 · Size S · Depends on: T11.4
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
Before filming, the app turns a script's visual notes into a shot list (phone-friendly page and printable PDF); after import, it shows coverage: which shots have matching clips and which are missing.

## Why
Planning the shoot from the script is how the building video gets filmed right the first time.

## Read first
- Script visual notes; T11.4 labels; T11.6 matching.

## Steps
1. Group visual notes into shots (location, subject, size).
2. Shareable page served by the app; PDF via Chromium print.
3. Coverage view after import.

## Acceptance
- Shot list and coverage for fixtures.

## Verify
```sh
.venv/bin/pytest tests/unit -q
```

## Don't
- No new LLM prompt beyond grouping.

## Implementer notes
*Added 2026-11-01 (Claude Opus 5.5).*

- Source: `Slide.visual_note` per paragraph (plain English). Group
  deterministically first (same location/subject words, consecutive paragraphs);
  an optional single LLM call may refine the grouping, behind a button, with the
  same token estimate + confirm pattern as T11.4, mocked in tests. Each shot keeps
  the paragraph ids it serves, a size (wide/medium/close/insert) and notes.
- Coverage needs matching, but T11.6 (clips into the edit) is not done. Implement
  only a simple matcher here: a shot is covered when an imported clip's T11.4
  labels share its subject/location terms (label overlap); show "covered",
  "maybe" and "missing". T11.6 can replace the matcher later.
- Page: one plain HTML route served by the app (checkbox per shot, large type,
  works on a phone), behind the existing remote-access token when bound beyond
  loopback. PDF: one `Page.printToPDF` through the existing CDP runner in
  `app/stage.py` (one page load, no per-page captures). If Chromium is missing,
  hide the PDF button.
- Store the shot list on the project (new field with an empty default; old
  projects load unchanged). Fixtures for tests: a three-paragraph script with
  visual notes and a fake shoot with labelled clips.
