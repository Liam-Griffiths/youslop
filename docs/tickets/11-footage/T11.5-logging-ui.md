# T11.5 Footage logger UI
Phase 11 · Size M · Depends on: T11.2, T9.3
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
A Footage screen: shoots list; clip grid grouped by label with hover-scrub filmstrips; a player with J/K/L shuttle, I/O to set in/out, number keys to apply labels, S to star, X to reject; bulk relabel; search by label, text and transcript.

## Why
Auto labels get you 80% there; a fast keyboard logger does the rest.

## Read first
- T11.1–T11.4 data; `timeline.js` keyboard patterns; T9.3 shell.

## Steps
1. Grid with sprites (CSS background-position scrub).
2. Player on proxies; in/out edits save to the clip.
3. Label palette (shoot vocabulary + model labels).

## Acceptance
- A user can log a shoot entirely from the keyboard; changes persist.

## Verify
```sh
CORKBORED_DATA=$(mktemp -d) .venv/bin/python scripts/ui_snapshots.py --out /tmp/ui
```

## Don't
- Never play originals in the browser; proxies only.
