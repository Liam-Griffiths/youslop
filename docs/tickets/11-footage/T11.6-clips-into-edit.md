# T11.6 Clips into the edit
Phase 11 · Size M · Depends on: T11.4, T9.8
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
Footage clips are a media provider ranked ahead of archives; each paragraph gets suggested clips by matching its visual note and narration to clip labels; choosing a clip stores source + in/out on the slide; the renderer cuts from the original (or proxy for previews) without transcoding the whole file.

## Why
The point of logging is to use it: the building video should mostly assemble itself from the shoot.

## Read first
- `app/media/providers.py` (library provider pattern), `MediaCandidate` (`kind='video'`, `duration`), `render.py` video handling (~672, `_stage_clips`), `T4.2` timing fields.

## Steps
1. Provider: query by labels + text; return candidates with `in_s/out_s` (extend MediaCandidate with optional in/out; schema rules).
2. Matching: cheap lexical score first; optional LLM re-rank of the top 20 (mocked in tests).
3. Render: `-ss in -t dur` on the source; previews use the proxy.

## Acceptance
- A fixture shoot fills a fixture script's paragraphs with relevant clips; renders use the trimmed range (graph golden).

## Verify
```sh
.venv/bin/pytest tests/unit -q
```

## Don't
- No full-file transcodes at render time.
