# T11.8 Export clips
Phase 11 · Size S · Depends on: T11.2
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
Selected clips export as files (stream copy where keyframes allow, else re-encode) named by label, with a JSON/CSV sidecar of labels and timecodes, for use in other editors.

## Why
Logged footage should be useful outside Corkbored too.

## Read first
- `ffutil`; T11.2 clips.

## Steps
1. Export dialog: folder, naming pattern, copy vs re-encode. The logger screen
   does not exist yet; expose a standalone `/footage/export` page from the sidebar
   with shoot and clip selection until that screen is implemented.
2. Sidecar with labels, in/out, source path.

## Acceptance
- Exported files play and match their in/out within a frame (re-encode) or a GOP (copy, noted).

## Verify
```sh
.venv/bin/pytest tests/unit/test_footage_export.py -q
```

## Don't
- Never overwrite an existing file; add a suffix.

## Implementer notes
- `Clip` has no labels field yet in this checkout; add a backwards-compatible
  `labels` list, defaulting to empty. Unlabelled exports use `clip` plus the ID.
- Read `footage.source_path` (linked or app-owned originals), never proxies.
- Re-encode exports are MP4 (H.264/AAC); stream-copy exports are Matroska to
  accommodate original codecs, with a GOP timing warning in the UI and sidecars.
- The naming pattern supports `{label}`, `{id}`, `{source}`; sanitize the result
  into a filename. Both JSON and CSV sidecars also receive collision suffixes.
