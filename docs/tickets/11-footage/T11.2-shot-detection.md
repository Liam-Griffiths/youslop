# T11.2 Shot detection into clips
Phase 11 · Size M · Depends on: T11.1
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
Each source file is split into candidate clips at camera cuts and long-take changes (scene-change score, motion/static transitions, silence), producing `Clip(id, file, in_s, out_s, thumbs)` with tiny clips merged and long holds split at a configurable maximum.

## Why
90 minutes as a handful of files is unusable; as 300 labelled clips it is a library.

## Read first
- `ffutil.run`; T11.1 proxies (detect on proxies, not originals).

## Steps
1. Scene scores with `select='gt(scene,T)',showinfo` (or `scdet`) on the proxy; motion energy per second from frame differences; audio silence via `silencedetect`.
2. Combine into boundaries; min clip 1.5 s, max 20 s (split long static holds at motion minima).
3. Store clips on the shoot; three thumbnails per clip (in, middle, out).
4. Tests on synthetic footage with known cut points (±1 frame).

## Acceptance
- Known cuts in synthetic footage are found within one frame; a 20-minute proxy is processed in under 2 minutes on the owner's machine (log the measurement). The performance measurement is deferred for this implementation because the owner's execution instructions prohibit benchmarks.

## Verify
```sh
.venv/bin/pytest tests/unit/test_shots.py -q
```

## Don't
- Do not decode originals; proxies only.

## Implementer notes
- T11.1's `ffutil.run` suppresses info logs by default but returns stderr;
  analysis passes explicitly supply `-loglevel info` for filter reports.
- `detect_shots(shoot_id, min_s=1.5, max_s=20)` is a synchronous worker called
  after `process_shoot`. It reads only proxies, including when originals are
  offline. Detection is an explicit operation; import/resume stays unchanged.
- `Clip.file` references `SourceFile.id`; `thumbs` paths are relative to the
  shoot directory. Existing shoots default to an empty clips list.
- Hard cuts take precedence over one-second motion/static changes and silence
  edges. Nearby boundaries are merged; a source shorter than the minimum stays
  as one clip. Maximum-length splits prefer motion minima in the last third
  of the allowed span, falling back to the latest feasible frame.
