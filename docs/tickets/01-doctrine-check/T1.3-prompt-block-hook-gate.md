# T1.3 Prompt block and hook gate
Phase 1 · Size M · Depends on: T1.1

## Goal
Every planner prompt receives the FrameSpec as plain-English numbers, the
outline carries a hook plan with open loops, and the cut `PLAN` prompts stop
hard-coding pacing numbers.

## Why
The planners write the cut. If they are told "fast" they guess; if they are
told "cuts every 0.13 to 0.8 seconds, average shot 1.8 to 3 seconds" they
comply and the check layer can verify. The hook gate is the WeAreNoCode rule
that the first three seconds decide the video.

## Read first
- `app/script_gen.py`: `build_outline`, `_write_section`, `plan_visuals`,
  `plan_cues` (where `module.PLAN` is inserted), `rewrite_slide`,
  `verify_script`, `NARRATOR_SYSTEM`.
- `app/cuts/flameboat.py` and one other cut: the `PLAN` string, find every
  literal number ("every 5-10 spoken words", "4 seconds").
- `FrameSpec.prompt_block` from T1.1.

## Steps
1. `build_outline`: add to the requested JSON an object
   `"hook": {"muted_image": str, "first_line": str, "open_loops": [{"question": str, "plant_beat": str, "payoff_beat": str}]}`
   and these rules in the prompt, verbatim in spirit:
   - "The first three seconds must work with the sound off: the first frame is
     a meaningful image, not a settling camera or a title alone."
   - "The first spoken word is clear of any card, sting or cut."
   - "Open at most one main loop at a time; every loop you plant names the beat
     that pays it off; close the promised lesson before any call to action."
   Store it as `project.outline["hook"]` (check how outline is stored).
2. Add pure `check_hook(outline)` findings for every `open_loops[*].payoff_beat`
   that does not name a section heading (trimmed, case-insensitive). Include
   these in `verify_script` even without research or slides.
3. Inject `project.frame.prompt_block(fmt)` into: `build_outline` (after an
   explicit format line; the current prompt has no format description),
   `_write_section` (include the title-hold and last-line rules), `plan_visuals` (after the available
   visual world), `plan_cues` (immediately after `module.PLAN`), `rewrite_slide`.
   Use one helper `_frame_text(project)` so there is one call site pattern.
4. Move Flameboat’s cue cadence to `PACE = {"cue_every_words": (5, 10)}`
   and remove its fixed four-second hold. Append generated pacing after PLAN:
   FrameSpec supplies shot duration and montage limits; PACE supplies the
   word cadence that FrameSpec lacks. Give the other cuts `PACE = {}`; retain
   their content limits and all kinds lists.
5. Tests `tests/unit/test_prompts.py`: assemble the `plan_cues` prompt for
   the fixture (factor prompt assembly into a pure function if it is inline)
   and snapshot it as a golden; assert it contains "per word" and the banned
   names. Mock the LLM; never call it in tests.

## Implementer notes
*Added 2026-10-26 after reading `script_gen.py`.*

- **`_normalise_outline` drops unknown keys.** It rebuilds the outline from
  a fixed list (title, subtitle, subject, era, thesis, visual_world,
  sections). Unless you add `hook` there, it is lost. Add a normaliser:
  ```python
  def _normalise_hook(raw: Any, beats: list[str]) -> dict:
      h = next((v for v in _walk_dicts(raw) if isinstance(v.get("hook"), dict)), {}).get("hook", {})
      loops = [l for l in (h.get("open_loops") or []) if isinstance(l, dict)][:3]
      return {"muted_image": str(h.get("muted_image") or "")[:300],
              "first_line": str(h.get("first_line") or "")[:300],
              "open_loops": [{"question": str(l.get("question") or "")[:200],
                              "plant_beat": str(l.get("plant_beat") or ""),
                              "payoff_beat": str(l.get("payoff_beat") or "")} for l in loops]}
  ```
  (`harvest()` already walks nested dicts for metadata; reuse that shape.)
  The outline is `project.outline: dict`, so `outline["hook"]` is stored with
  no schema change.
- **"Beats" are section headings.** Tell the model that `plant_beat` and
  `payoff_beat` must be copied exactly from `sections[*].heading`. Match
  case-insensitively and trimmed.
- **Do not put the payoff check inside `verify_script`'s LLM path.** It
  returns `[]` early when there is no research dossier and only talks to
  the model. Write a pure `check_hook(outline) -> list[dict]` and append its
  results at the end of `verify_script` (outside the `if not facts` early
  return; restructure the early return). T1.5's `open_loop_unpaid` will call
  the same helper.
- **Only one cut has pacing numbers in `PLAN`:** `flameboat.py` ("every 5-10
  spoken words", "more than about 4 seconds"). The numbers in the other four
  (`max 20 words`, `2-6 words`, `1-4 cues per paragraph`) are content
  limits, not pacing: leave them in `PLAN`. So `PACE` is only needed in
  `flameboat.py`; give the others `PACE = {}` for a uniform interface. Use
  `str.format`-style placeholders in PLAN (`{cue_every}`) only if you escape
  the JSON braces already in it (they are literal `{"kind": ...}`); simpler
  to append a generated "Pacing:" paragraph after `module.PLAN` and delete
  the sentence from PLAN.
- **Factor the prompt out first.** `plan_cues` builds its prompt inside the
  nested `run()`. Make
  `_cues_prompt(project, module, chunk, facts) -> str` at module level and
  call it from `run`; snapshot that. Same for `build_outline`:
  `_outline_prompt(project, n_beats, ...) -> str`. Tests then need no
  mocking at all.
- `_frame_text(project)` = `project.frame.prompt_block(project.style.format)`;
  put a heading line `PACING AND HOUSE RULES:` before it so the model sees it
  as a block.
- The real test (acceptance): create a test project from the UI (New video
  → test run, one minute), let it outline, then
  `python -m app.cli storyboard <pid> --json | jq .project` or open
  `project.json` and read `outline.hook`. One run only; the owner pays for
  it.
