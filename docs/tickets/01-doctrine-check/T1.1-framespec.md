# T1.1 FrameSpec dataclass
Phase 1 · Size M · Depends on: T0.5

## Goal
A `FrameSpec` dataclass in `app/schema.py` holds every pacing, motion,
typography and sound number as data, lives on `Channel` and `Project`, and
has sensible defaults taken from the Hyperframes and WeAreNoCode doctrine.

## Why
Hyperframes' rule is "turn every adjective into a number". Today the numbers
are scattered as literals in `render.py`, `kit.py`, `titles.py` and the cut
`PLAN` prompts. One spec means the planner prompts, the renderer and the
check layer agree, and a channel can own its own look.

## Read first
- `app/schema.py`: `Style`, `Channel`, `Project`, `new_project` (how `style`
  is copied from a channel), the `to_dict`/`from_dict` pattern.
- `app/main.py`: `patch_project` (how `style` fields are patched; note it
  casts scalars with `type(current)(value)`, which will not work for a dict).
- `docs/roadmap.md` §4 "Doctrine → code mapping" for where each number lands.

## Steps
1. Add to `app/schema.py`:
   ```python
   @dataclass
   class FrameSpec:
       # motion
       arrive_s: float = 0.45          # entrance length, expo.out
       exit_ratio: float = 0.55        # exits are 40-50% shorter than entrances
       move_min_s: float = 0.3
       move_max_s: float = 0.6
       # titles and captions
       title_hold_base_s: float = 0.5
       title_hold_per_word_s: float = 0.3
       last_line_min_s: float = 2.0
       title_height_pct_min: float = 4.0
       title_height_pct_max: float = 9.0
       # cuts and pacing
       montage_cut_min_s: float = 0.13
       montage_cut_max_s: float = 0.8
       shot_avg_min_s: float = 1.8
       shot_avg_max_s: float = 3.0
       payoff_hold_min_s: float = 0.3
       payoff_hold_max_s: float = 0.75
       transition_types: list = field(default_factory=lambda: ["cut", "fade", "dip"])
       max_gap_first_90_s: float = 15.0
       max_gap_after_s: float = 20.0
       max_gap_ever_s: float = 30.0
       hook_s: float = 37.0
       overlays_per_hook: int = 6
       overlays_per_90_s: int = 7
       camera_moves_per_90_s: int = 7
       # camera
       creep_min: float = 1.10
       creep_max: float = 1.12
       punch_min: float = 1.18
       punch_max: float = 1.25
       camera_origin: str = "top"      # top-anchored origin
       snap_on_cut: bool = True
       # anchoring
       anchor_after_s: float = 0.10    # element may enter this long AFTER its word...
       anchor_before_s: float = 0.60   # ...or this long BEFORE it
       # sound
       music_under_min_db: float = 16.0  # music bed this far under the voice...
       music_under_max_db: float = 19.0  # ...to this far (no ducking; see T1.7)
       voice_lufs: float = -14.0
       # taste
       banned: list = field(default_factory=lambda: list(BANNED_DEFAULTS))
       rejected_looks: list = field(default_factory=list)
       rules: list = field(default_factory=list)       # plain-English rules, learning loop
       design_md: str = ""                              # brand notes
       frame_md: str = ""                               # how the brand plays in 16:9
   ```
   with `BANNED_DEFAULTS = ["breathing_loop", "title_moves_after_landing",
   "same_entrance_everywhere", "fade_slide_up_everything", "whoosh_under_text",
   "bounce_on_ui", "slow_creeping_scale"]` and a dict `BANNED_MEANINGS`
   giving each a one-line description for prompts and the UI.
2. `to_dict()` / `from_dict()` in the same style as `Style`, ignoring unknown
   keys and defaulting missing ones. Add `frame: FrameSpec` to `Channel` and
   `Project`; `new_project` copies the channel's frame like it copies style
   (deep copy). Old JSON without `frame` must load.
3. `FrameSpec.prompt_block(fmt: str) -> str`: a plain-English paragraph set,
   every number spelled out as a sentence ("Hold a title for 0.5 seconds plus
   0.3 seconds per word."), followed by "Banned by name:" and the meanings,
   then "House rules:" and `rules`. Keep it under 60 lines of text. T1.3
   injects it; write it here so it is tested with the spec.
4. `main.patch_project` and the channel patch endpoint: accept a `frame`
   dict, merge key by key onto the existing spec with type coercion from the
   dataclass field type, reject unknown keys with a 400.
5. `storyboard.build()` (T0.7) fills `frame` with `project.frame.to_dict()`.
6. Tests `tests/unit/test_framespec.py`: defaults round-trip; `from_dict({})`
   equals defaults; `from_dict` ignores an unknown key; `prompt_block` contains
   "0.3 seconds per word" and every banned name; patch merge coerces `"0.4"`
   to `0.4` and rejects `"nonsense"`.

## Implementer notes
*Added 2026-10-26 after reading `schema.py` and `main.py`.*

- **`Project.to_dict` and `Channel.to_dict` are hand-written**, not
  `asdict`. You must add `"frame": self.frame.to_dict()` to both, and add
  `"frame"` to the excluded-keys set in both `from_dict`s (Project: the
  `known = ... - {"slides", "style", ...}` line ~752; Channel: ~531), then
  pass `frame=FrameSpec.from_dict(d.get("frame") or {})`. Miss the exclusion
  and a saved `frame` dict is passed raw into the constructor.
- `FrameSpec.from_dict` pattern used everywhere in this file:
  ```python
  @classmethod
  def from_dict(cls, d: dict) -> "FrameSpec":
      known = cls.__dataclass_fields__
      return cls(**{k: v for k, v in (d or {}).items() if k in known})
  def to_dict(self) -> dict: return asdict(self)
  ```
  Lists in defaults use `field(default_factory=...)`; `asdict` deep-copies
  them, so `FrameSpec.from_dict(channel.frame.to_dict())` in `new_project`
  is a safe deep copy (that is how `style` is copied today, line ~815).
- **Merge with coercion** (step 4). One helper, used by both endpoints and
  by T1.2 and T4.7:
  ```python
  def merge(self, patch: dict) -> "FrameSpec":
      """New spec with patch applied. ValueError on unknown key or bad value."""
      out = FrameSpec.from_dict(self.to_dict())
      for k, v in patch.items():
          f = FrameSpec.__dataclass_fields__.get(k)
          if f is None:
              raise ValueError(f"unknown frame field: {k}")
          cur = getattr(out, k)
          if isinstance(cur, bool):   v = v if isinstance(v, bool) else str(v).lower() in ("1", "true", "yes")
          elif isinstance(cur, (int, float)): v = type(cur)(float(v))   # "0.4" -> 0.4; "x" raises
          elif isinstance(cur, list): v = [str(x) for x in v] if isinstance(v, list) else _bad(k)
          else: v = str(v)
          setattr(out, k, v)
      return out
  ```
  Check `bool` before `int` (bool is a subclass of int). In `patch_project`
  (~line 979) and `patch_channel` (~283), add before the `style` loop:
  `if isinstance(payload.get("frame"), dict): try: p.frame = p.frame.merge(payload["frame"]) except ValueError as e: raise HTTPException(400, str(e))`.
  `GET /api/projects/{pid}` returns `p.to_dict()`, so `frame` shows up once
  `to_dict` has it.
- `BANNED_DEFAULTS` must be defined **above** `FrameSpec` in the file (the
  default factory closes over it at call time, so strictly it only has to
  exist before first instantiation, but put it above for readability).
- `prompt_block(fmt)` is a method on a dataclass: keep it pure (no imports
  from `cuts`). The `fmt` argument only selects which paragraphs to include
  (drawn cuts get the montage numbers; `kenburns`/`essay` get camera and
  title numbers). Golden-test it; T1.3 snapshot depends on it.
- Old projects: `test_framespec.py` should load
  `tests/fixtures/project_min.json` (which has no `frame`) and assert
  `p.frame == FrameSpec()`.
