# T10.6 Sponsors in the editor
Phase 10 · Size M · Depends on: T10.1, T9.10 (or T4.4)
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
The Edit stage shows a sponsor lane: add a sponsor, pick short or long, drag to a boundary (snapping to paragraph ends), preview it, toggle it off.

## Why
Placement is visual; the timeline is where it belongs.

## Read first
- `static/js/timeline/{core,layers,inspect,edit,playback}.js` (T4.4).
- `app/schema.py` `SponsorSlot`; `app/sponsors.py` placement helpers;
  `app/render.py` `timeline`, `proxy_ref`; `app/main.py` `patch_project`, `timeline_proxy`.
- `app/blocks.py` `prepare`; `app/scene_builder.py` `render`;
  `static/blocks/sponsor_short`, `static/blocks/sponsor_long`.

## Steps
1. Lane with sponsor blocks at their times; drag snaps to allowed boundaries; inspector shows sponsor, variant, copy, take.
2. Preview renders the segment at quarter size.

## Acceptance
- Add, move, switch variant, disable and preview all work and persist.

## Verify
```sh
CORKBORED_DATA=$(mktemp -d) .venv/bin/python scripts/ui_snapshots.py --out /tmp/ui
```

## Don't
- Never render the whole cut to preview a sponsor.

## Implementer notes
- T10.1 provides the serialized slot model and timeline data, but no writable
  SponsorSlot HTTP API: add narrow create/update routes here. Keep take/history
  server-owned. T4.4 already supplies the sponsors row; extend it.
- T10.2 is deferred. Enter name and copy inline; `sponsor_id` remains the hook
  for a future library. No house read is added automatically.
- Preview through the scene builder's core sponsor blocks, one segment at
  quarter size. Block catalog duration ranges are authoring guidance; the actual
  slot take/script duration drives this preview. Do not replace existing takes.
