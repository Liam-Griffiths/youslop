# T10.7 Description, chapters and YouTube flags
Phase 10 · Size S · Depends on: T10.1, T10.2
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
The description gets a sponsor block (link, code, disclosure) and a 'Sponsor' chapter; uploads with a paid sponsor set YouTube's paid-promotion flag; the house read only adds its link.

## Why
Links in the description are the point of the read; disclosure is a legal requirement for paid ones.

## Read first
- `youtube.build_description`, `chapter_points`, `upload_video` (~213).

## Steps
1. Add a description block per enabled slot from its copied vars (name, url,
   code and paid disclosure in `made`). The house read adds only its link line.
   Use final-cut timeline starts for Sponsor chapters; skip conflicting markers
   with a note to preserve YouTube's 0:00, three-chapter and 10-second rules.
2. Leave `status.containsSyntheticMedia` untouched. For enabled paid slots only,
   include `paidProductPlacementDetails.hasPaidProductPlacement=true` in the
   insert body and part list. If that part is rejected, retry initiation without
   it; if rejected or missing/false in the completed insert response, make one
   `videos.update` with `part=paidProductPlacementDetails` after upload.
   Use the owner's 2026-11-08 API findings (no network verification required).

## Acceptance
- Description and chapter output for fixtures; upload request body includes the flag only for paid sponsors (mocked).
