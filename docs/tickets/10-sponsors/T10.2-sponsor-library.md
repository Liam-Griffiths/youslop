# T10.2 Sponsor library on channels
Phase 10 · Size S · Depends on: T10.1
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
Channels keep reusable sponsors (name, logo, brand colours, link, promo code, short and long copy, disclosure line, paid or house) and a project slot picks one; a built-in house sponsor, **Corkbored**, ships with the app.

## Why
Sponsors recur across a channel's videos; the read should be set up once. The owner's first sponsor is the house read: "This video was made with Corkbored...".

## Read first
- `app/channels.py`, `Channel.to_dict`/`from_dict` (NOTES.md traps); T10.1.

## Steps
1. `Sponsor` dataclass on Channel (`sponsors: list`), CRUD routes, CLI `sponsor list|add`.
2. House sponsor built in (not stored per channel): name Corkbored, link corkbored.com, short copy "This video was made with Corkbored. Learn how you can build your own videos, with the link in the description below.", template `sponsor/house_short.html`, paid=false.
3. **Owner decision (2026-11-08): opt-in.** The house read is never added to a project automatically; the user picks it in the slot like any sponsor. Keep the setting, defaulting to opt-in.

## Acceptance
- A channel sponsor can be created, edited, chosen in a slot; the house sponsor is always available.
