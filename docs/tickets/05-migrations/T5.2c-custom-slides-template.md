# T5.2c Custom slides through a scene template
Phase 5 · Size S · Depends on: T5.2a

*Split from the old T5.2 on 2026-10-26.*

## Goal
Custom slides render through one scene template from the JSON spec they
already have (positioned elements with reveal order and arrival), with no
prompt changes.

## Why
The spec is already positional: each element has `type`, `x, y, w, h` as
fractions of the frame, an `order` and an arrival animation. That maps
one-to-one onto absolutely positioned elements, so this is a small,
safe step before T5.2d changes what the model writes.

## Read first
- `app/custom_slide.py`: `normalise` (~171: element fields and defaults),
  `TYPE_KEYS`, `resolve_images` (~244), `_layout` (~275), `_build_tile`
  (~285), `_anim` (~337: arrival kinds), `frames` (~369), `candidate`
  (~427).
- `app/render.py`: `_render_custom_style` (~333).
- `static/js/core.js`: `CUSTOM_ANIMS`, `CUSTOM_FONTS`, `CUSTOM_SIZES`:
  the editor vocabulary (moved out of `static/app.js`).

## Steps
1. `static/scene/slides/custom.html`: one absolutely positioned element per
   spec element (`left: x*100%` etc.), text in the chosen font/size class,
   photos via `/scene/<token>/project/`, shapes as divs. Each element is a
   `.clip` with `data-start` from the same reveal schedule `frames` uses,
   and `data-anim` mapped from `_anim`'s kinds (`fade, rise, fly-left,
   fly-right, pop, none`). Position each fitted text line with a Python-
   computed alphabetic baseline (`i * line_h - font.getbbox(line, anchor='ls')[1]`)
   in SVG text, preserving Pillow's per-line top anchor without CSS leading.
2. Add `Style.custom_engine` (default `scene`, fallback `pillow`).
   `_render_custom_style` keeps its signature; standalone `candidate` and
   `render_still` accept an optional engine, defaulting to Pillow like the
   diagram helpers. The slide candidate endpoint passes `style.custom_engine`.
   Capture settled element plates once; ffmpeg handles entrances and holds.
3. Compare stills for three saved-style fixtures under
   `docs/tickets/05-migrations/compare/custom/`. When Chromium is unavailable,
   provide fixtures and reviewer commands there; leave visual acceptance pending.

## Acceptance
- Existing custom-slide projects render through the scene with elements in
  the same places and order.

## Verify
```sh
.venv/bin/pytest tests/unit/test_custom_scene.py -q
```

## Don't
- Do not delete `diagram.py`, `custom_slide.py` or `board.py`.
- One paragraph previews while developing; never a full render.
- No prompt changes (that is T5.2d).

## Implementer notes
- Add the runtime presets T2.2 lacks (`fly-left`, `fly-right`, `pop`) to
  `runtime.js` rather than per-template JS.
- The test: render the template's HTML for a fixture spec and assert one
  element per spec element with the right `left/top/width/height`
  percentages (string check; no browser).
