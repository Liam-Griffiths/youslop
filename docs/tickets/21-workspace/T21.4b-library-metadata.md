# T21.4b Library: ratings, colour labels, filters, batch labels, collections
Phase 21 · Size M · Depends on: T21.4

## Goal
Bridge/Lightroom-style culling: 1–5 star ratings, colour labels, a filter bar
(kind, rating ≥, colour, label, used/unused, orientation), batch labelling,
and saved collections (smart and manual).

## Read first
- T21.4, `LibraryAsset` in `app/library.py`, the label vocabulary component
  from T21.2c (`static/ui/labels.js`; reuse it).

## Steps
1. `LibraryAsset` gains `rating: int` (0–5), `color: str` (`"" | red |
   yellow | green | blue | purple`), keeping `tags` as labels. Unknown keys
   ignored; old index loads.
2. Keys: 0–5 set rating, 6–9 set colour labels (red, yellow, green, blue;
   same as Bridge), `\`` clears colour; apply to the whole selection, one
   write. Stars and colour show on tiles and in the details list.
3. Filter bar above the grid, all combinable, remembered per tree node:
   kind, rating ≥ N, colour, labels (any/all), used in a project / unused,
   orientation (landscape/portrait/square), added date range.
4. Batch labels: with a multi-selection, the preview pane's label editor adds
   or removes labels across all of them; the shared vocabulary editor
   (rename, merge, delete with confirm) from T21.2c.
5. Collections: "Manual" (drag items in) and "Smart" (a saved filter). Stored
   in `library.json` as `collections: [...]`; appear as tree roots.
6. "Used in" (projects referencing an asset) computed on demand and cached
   per session; shown in the preview pane.
7. Tests: index round trip with old data, batch rating/label writes, smart
   collection filter evaluation.

## Acceptance
- Rate and colour-label 20 assets with keys in under a minute; filter to
  "★★★★+ green, unused" works and is saved as a smart collection.
