# T21.3b Corkboard view: the outline as cards inside Script
Phase 21 · Size M · Depends on: T21.3

## Goal
Script's "Outline" view is a corkboard of index cards (Scrivener's
corkboard): one card per beat/paragraph, grouped in chapter columns, with the
synopsis on the card. It replaces the separate Plan stage and is where
"Write the script" (from an outline) and hook editing live.

## Why
The owner found Plan-as-stage-one confusing. Planning is part of writing:
Scrivener keeps the corkboard one toggle away from the editor. The app is
even named for it. (Chrome stays Instrument: cards are flat `--panel` tiles,
no cork texture, per design guide §1.)

## Read first
- `static/js/tabs/plan.js` (`paintPlan`, `planSources`, `planChapters`,
  `planDraw`, beat drag), `app/plan_board.py` and its routes, T20.10 (now
  superseded: fold its board-fit fixes in here).
- T21.3's view toggle.

## Steps
1. Move Plan's functionality into `static/js/tabs/script_outline.js`,
   rendered when Script's view toggle is "Outline" (route
   `#/p/<id>/script?view=outline`; `#/p/<id>/plan` redirects here).
2. **Before a script exists:** the board shows the outline's beats as cards
   (from `/plan`), the hook card on top with its "works muted" check, the
   sources column collapsible on the left, and the one accent action "Write
   the script". After it exists, cards are paragraphs: first line of
   narration as title, `visual_note` as synopsis, word count, take state,
   finding dot; beats with no paragraph show dashed.
3. Cards are draggable within and between chapter columns (same sections
   API as the binder; Alt+arrows from the keyboard). Double-click / Enter
   opens that paragraph in the Write view with the caret in it. Card size
   slider (S/M/L) like Scrivener; columns scroll horizontally, the board
   fits 1280×720 without a vertical page scroll for ≤ 6 chapters (T20.10).
4. Add-card (dashed) at the end of each column creates an empty paragraph
   or beat. "Write the script" regenerates only changed beats (existing behaviour).
5. Remove Plan from anything still pointing at it as a stage; keep the API.
6. Mark T20.10 `dropped (superseded by T21.3b)` in its ticket file Log
   (the manager updates PROGRESS).

## Acceptance
- A new project (idea only) shows outline cards and can write the script
  from them; a scripted project shows paragraph cards in chapter columns.
- Drag between columns reorders and re-chapters with one undo step.
- `#/p/<id>/plan` lands on the corkboard. No Plan stage remains.
