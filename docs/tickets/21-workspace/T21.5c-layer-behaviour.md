4. Persist hide/lock edits using the app's existing edit/history flow.

5. Enforce locks in every relevant UI gesture and API (409), including batch
   edits, cross-paragraph moves, split, trim, replace and delete. Check both
   source and destination layers before saving anything.
6. Retain fallback tracks for populated roles missing from a partial saved
   configuration. Prevent duplicate ids (including collisions with derived
   track ids). Do not rewrite unknown/missing item assignments on load.
