# T21.6b Pictures, clips and 3D on upper layers (picture-in-picture)
Phase 21 · Size L · Depends on: T21.6

## Goal
Besides blocks, a creator can put a picture, a clip, or a 3D shot on an upper
layer above the main track, with its own in/out time, position, size and a
simple fade in/out — e.g. an archive photo inset over a map, or a clip in a
corner over a diagram.

## Why
Owner: "layer images/3D/clips/blocks… choose timings". Today only blocks can
sit above the main picture (T12.10, T17.6).

## Read first
- `Slide.overlays` and `app/block_overlays.py` (`resolved`), T17.6 overlay
  drag/trim code, `app/scene_builder.py` (layers, grounds), `camera_overlays.py`
  (an existing video-over-picture path), `app/render.py` `_layers` and the
  segment compositor, T21.5's layer roles.
- NOTES.md: render pipeline facts and the still-decode trap.

## Steps
1. New layer role `media` (Pictures-like upper track). Item shape on the
   slide's `overlays` list with `type: "media"`: `source` (bin id, library
   id, candidate url-cached file, or 3D shot id), `at`, `dur`, `in` (clip
   source offset), `box` (x, y, w, h in 0–1 frame units), `fit`
   (cover/contain), `fade_in`, `fade_out`, `volume` (clips; default 0).
2. Render: composite media items in the builder/ffmpeg path in layer order
   with blocks, decoding stills once (see the still-decode trap). Clip audio
   mixes at `volume` under narration, ducked like inserts. Old projects
   without media items render byte-identical (goldens).
3. Timeline: drop from the sources panel onto a media layer; move, trim
   both edges, slip with Alt (clips), duplicate, delete — reuse T17.6 code.
4. Inspector: box presets (full, inset top-right, inset bottom-left, left
   half, right half) plus numeric x/y/w/h in mono; fades; volume.
5. Player preview shows the box outline over the picture when selected;
   drag the box to move, corner to resize (preview only, writes `box`).
6. Tests: model round trip, render graph for one inset still and one inset
   clip (graph goldens), audio mix level, unchanged goldens otherwise.

## Acceptance
- An inset photo over a paragraph renders in a quarter-size section preview
  at the set box with fades.
- A muted clip inset plays its chosen source range.
- Existing goldens unchanged.
