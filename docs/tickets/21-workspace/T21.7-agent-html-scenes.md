# T21.7 Ask the agent for a custom HTML scene, placed on a layer
Phase 21 · Size M · Depends on: T21.6, T21.5b

## Goal
In Edit's sources panel, an **Agent** tab takes a plain request ("an animated
map of the 1863 Metropolitan line, stations popping in as they're named") and
builds an HTML-driven scene with the existing block-creation pipeline, using
the paragraph's narration, word timings, facts and the project's look as
context. It previews at quarter size and drops onto the chosen layer at the
selected time and length.

## Why
Owner: "ask for a custom agent creating HTML-driven stuff, choose timings etc."
The pipeline exists (`app/block_creation.py`, "Design a block…" in
`style_picker.js`) but is buried in the style picker and knows nothing about
where the scene goes.

## Read first
- `app/block_creation.py` (`prompt_for`, `describe`, lint/check loop),
  `block_authoring.py`, `block_sandbox.py`, `designStyleBlock` in
  `static/js/tabs/style_picker.js`, `custom_scenes.py`, T17.6 overlay
  placement, T21.6 sources panel.
- `docs/design/studio-flow.md` principle 3 ("The model decides, code draws").

## Steps
1. **Agent tab UI:** request textarea; target (the selected picture's
   paragraph or the playhead position), mode "Full frame (replace picture)"
   or "Overlay on <layer>"; length (default: the paragraph's spoken length
   or 5 s); a Generate button (accent within the panel only if Edit has no
   other accent; otherwise Light button).
2. **Context:** pass narration of the target paragraph(s), its word timings
   (so the agent can time reveals to words, as cue times), up to 10 linked
   facts, project palette/fonts (block theme), aspect and length. Extend
   `prompt_for` with an optional context argument; keep the old call working.
3. **Job:** runs through `jobs.start` (slow work outside the lock), uses the
   existing lint/check/sandbox loop, saves as a user block under the project
   (`user/<id>`), then renders a quarter-size poster + short preview.
4. **Place:** on success the result card shows the preview with "Place",
   "Try again" (keeps the request, adds the creator's follow-up), "Edit
   request". Place inserts it as a full-frame insert/picture replacement or
   an overlay on the chosen layer at the chosen time — one undo step.
5. Scenes made this way list under Blocks → "Made for this project", reusable.
6. Tests with monkeypatched `complete_json`: context reaches the prompt,
   failure leaves no partial block, placement creates the right overlay.

## Acceptance
- With a mocked model, a request produces a sandbox-valid block, a preview,
  and an overlay at the playhead on the chosen layer.
- A real run (reviewer, one request, quarter-size preview) produces a
  scene timed to the narration.
