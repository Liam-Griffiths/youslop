# T21.6 Edit becomes the composing stage: sources panel, Visuals folds in
Phase 21 · Size L · Depends on: T21.5, T21.2

## Goal
Edit is where pictures are chosen and arranged. A **sources panel** on the
left offers the project bin, the Library, archive search, blocks, 3D models
and (after T21.7) "Ask the agent"; anything drags onto the timeline. Selecting
a picture shows its candidates in the inspector. "Fill the rest", "Plan all
shots" and the visual mix bar move here. The Visuals tab is retired.

## Why
Owner: "Visual I'm not sure, maybe this should be more of an editing, where I
can layer images/3D/clips/blocks… choose timings etc. Edit I like."
Choosing pictures in one stage and timing them in another doubles the work.

## Steps
1. **Layout:** sources panel (left, 300 px, collapsible with `\`), player
   and inspector (as today), lanes below. At 1280×720 the player, at least
   the Pictures and Voice lanes and the playhead are visible without
   scrolling (T20.4).
2. **Sources panel tabs:** Bin · Library · Search (archive providers) ·
   Blocks · 3D · (Agent, placeholder disabled until T21.7). Each is a
   thumbnail grid with a search box; the Add panel from T17.3 becomes this
   panel's content (don't keep two). Drag rules:
   - onto a picture on the Pictures lane → replaces that picture (sets
     `chosen_id`, `locked_media`), undoable;
   - onto an edit point / between pictures → insert (T17.2 inserts);
   - a block onto a graphics layer → overlay (T17.6);
   - double-click a source → applies to the selected picture.
3. **Inspector for a picture:** preview, candidates strip (from
   `Slide.candidates`), "Search again" with editable queries, upload,
   map controls for map pictures, picture mode (auto/hold/new), kind, the
   shot description from Script (editable, same field), lock toggle.
4. **Stage-level actions** in a toolbar over the lanes: Fill the rest,
   Plan all shots (3D), Auto-edit cutaways where applicable, visual mix bar
   (compact) with the format rule.
5. **Retire Visuals:** the Edit stage's temporary "Pictures | Timeline"
   toggle from T21.1 goes; `visuals|media|cast|stage` routes open Edit
   with the matching sources tab selected. Delete `visuals.js` only after
   every capability is re-homed (note in Log); keep shared helpers.
6. Mark T20.13 and T20.4 superseded in their ticket Logs.
7. Snapshot fixtures: Edit with sources panel on each tab, picture selected
   with candidates, 1280×720 and 1920×1080.

## Acceptance
- From Edit alone a creator can: choose or replace any picture, search
  archives, use a bin item, drop a block overlay, place a 3D shot, fill the
  rest — no other stage needed.
- 1280×720 shows player + Pictures + Voice lanes + playhead without scrolling.
- Old routes open the right sources tab. Nothing previously possible is lost.
