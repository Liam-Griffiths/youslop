# T21.4 Library as an explorer: tree, grid, preview pane
Phase 21 · Size L · Depends on: —

## Goal
The Library screen (`#/library`) works like Adobe Bridge or a file explorer:
a **folder tree** on the left, a **thumbnail grid** in the middle with a size
slider and a list/details toggle, and a **preview + metadata pane** on the
right. Keyboard and multi-select work like a desktop file browser.

## Why
Owner: "the library section needs to feel more like an explorer, like Bridge."

## Read first
- `app/library.py` (`list_all`, `list_folders`, `add_folder`, `scan_folder`,
  `update`, `remove`, thumbnails) and its routes in `app/main.py`.
- The current Library UI (grep `library` in `static/js/`, `shell.js` nav).
- Footage shoots (`app/footage.py`) and project bins (T21.2, if landed) as
  extra tree roots.

## Steps
1. **Tree** (left, 260 px, resizable): roots — "All media", "Uploaded",
   each linked folder (with its real subfolders, built from asset paths, not
   by walking the disk again), "Footage" → shoots, "Projects" → each
   project's bin (read-only references; only if T21.2 is done, else hide),
   "Recent" (last 50 added). Counts in mono. "+ Link a folder" and
   "Rescan" at the bottom. Expand/collapse with arrows.
2. **Grid** (middle): thumbnails sized by a slider (80–320 px, remembered),
   filename/title under each, kind badge, mono duration for clips. Toggle to
   a details list (name, kind, size, dimensions, duration, added, labels)
   with sortable columns. Hover-scrub for clips (proxy/thumbnail strip if
   available; otherwise just the poster). Lazy-load thumbnails
   (`loading="lazy"`, IntersectionObserver) so 5,000 items scroll smoothly.
3. **Selection:** click, Shift-click range, Ctrl/Cmd-click toggle, marquee
   drag, Ctrl+A; arrow keys move focus in the grid (row-aware), Space opens
   a large preview overlay (Esc closes; ←/→ step), Enter opens the item.
4. **Preview pane** (right, 340 px): large preview (image, playable clip,
   audio waveform/player), then metadata in mono (file name, path for linked
   folders with "Show in folder", dimensions, duration, size, added, source,
   licence/credit fields if present), editable title and tags (labels).
   With several selected: count and shared labels editable for all.
5. **Breadcrumb + search bar** above the grid: path of the tree node, a
   search box (title, tags, filename), kind filter chips.
6. **Drag out:** dragging items from the grid sets a drag payload that
   Edit's sources/timeline (T21.6) and the project bin (T21.2) accept as a
   Library reference.
7. Snapshot fixtures: empty library, ~60 mixed items grid, details list,
   multi-select with preview pane, 1280×720.

## Acceptance
- A linked folder with subfolders shows as a tree; selecting a subfolder
  filters the grid.
- 1,000 fixture assets scroll without layout jank (thumbnails lazy).
- Keyboard: arrows, Shift+arrows, Space preview, Ctrl+A all work.
- No file in a linked folder is ever written, moved or deleted.
