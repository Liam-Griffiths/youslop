# T21.3c Script inspector: matched facts and private notes
Phase 21 · Size M · Depends on: T21.3, T21.2b

## Goal
Complete the writing inspector with paragraph-specific research, searchable
facts, insertion at the caret, and a private paragraph note.

## Why
Split from T21.3 on 2026-11-15 under its Implementer notes: the resumed
layout, binder, editor, preservation fixes and verification exceed ~600
changed lines. T21.3 keeps all existing research and paragraph controls.

## Read first
- `static/js/tabs/script.js`: `paintScript`, `sourcesPanel`, `scriptSave`.
- `static/js/tabs/script-writing.js`: `scriptCurrent`, `scriptInput`,
  `scriptFlush`, `scriptDetail`; preserve the serialized save queue.
- `app/schema.py`: `Slide`, `Project.research`; `app/edits.py`:
  `EDITABLE`, `patch_slide_fields`; `app/main.py`: `patch_slide`.
- T21.2b's bin notes and `docs/design/studio-flow.md`.

## Steps
1. Keep the inline Shot header and inspector order Facts, Title, Findings,
   Notes (T21.3 owner update). Preserve the
   existing source links, confidence, dates, open questions and corrections.
2. Match facts to the current paragraph using existing explicit linkage if
   available, then `beat`, then simple deterministic text overlap. Show
   matched facts first and provide searchable All facts, including source
   title/link and date. Include the project's bin notes after T21.2b.
3. Add Insert to put a claim at the saved narration caret as plain text.
   Preserve the caret when interacting with the inspector and send the edit
   through `scriptInput`/`scriptSave`, retaining takes and undo behavior.
4. Add `Slide.note: str = ""`, editable only as private Notes. Round-trip
   through the schema and PATCH validation. Never include it in narration,
   generation prompts, spoken audio, captions, shot lists or renders.
5. Keep collapse preferences and blocked-storage fallbacks; update synthetic
   snapshot fixtures with matched/unmatched facts, bin notes and private notes.

## Acceptance
- Relevant facts appear first; All facts filters deterministically.
- Insert edits the intended paragraph/caret and preserves recordings.
- Notes survive saving/reloading old and new projects and never enter output.
- Unit tests cover note defaults/round trips, fact matching and caret insertion.
