# T21.5b Layer manager and agent-proposed layers
Phase 21 · Size M · Depends on: T21.5

## Goal
Creators add, rename, recolour, reorder, hide, lock and delete layers from
the timeline, and move items between layers of the same role. When a script
is written, the agent proposes a small layer set that fits this video; the
creator accepts it in one click or edits it.

## Why
Owner: "layers should be custom to the project, defined by the agent at
first; users can add more etc."

## Read first
- T21.5 (`Layer`, `layers.effective`), `app/llm.py` `complete_json`,
  `app/script_gen.py` (where a finished script is saved), `block_suggest.py`
  (an existing "model chooses from a fixed menu" pattern).

## Steps
1. **Timeline label column:** double-click a name to rename; a "⋯" menu with
   Colour, Lock, Hide, Hide in render, Duplicate layer (empty), Delete; drag
   the label to reorder; a "+ Layer" button at the bottom asks for a role
   (Graphics, Titles, Music, Notes…) and a name. Delete is allowed on empty
   layers; on a non-empty one the app dialog offers "Move items to <layer>"
   (same role) — never deletes items silently. Pictures and Voice can be
   renamed but not deleted.
2. Moving an item to another layer: drag vertically onto a layer of the same
   role, or the inspector's "Layer" select. One undo step each.
3. **First edit persists:** any layer edit writes `effective(project)` to
   `project.layers` and applies the change.
4. **Agent proposal.** After script generation completes (and from a
   "Suggest layers" button), one `complete_json` call with the script
   outline, format and channel returns 3–8 layers: `{name, role, why}`
   choosing roles only from the fixed menu, names ≤ 24 chars. Validate;
   discard unknown roles. Show it as a proposed change (design guide
   "Proposed change" component) in Edit: Apply / Dismiss. Applying creates
   the layers and assigns existing items by role (first layer of each role).
   Local models: the call is small; if it fails, no proposal, no error toast
   beyond the jobs strip.
5. Tests: monkeypatched `complete_json` → proposal validation, apply
   assignment, delete-with-move, rename, reorder, undo.

## Acceptance
- A creator can make "Maps" and "Diagrams" graphics layers, move overlays
  between them, reorder them, and the preview stacks them accordingly.
- After writing a script, a layer proposal appears and applies in one click.
- No item is ever lost when deleting a layer.
