# T21.6b1 Media-layer placement, controls and 3D
Phase 21 · Size L · Depends on: T21.6b

## Goal
Finish T21.6b's user-facing workflow for inset pictures, clips and 3D shots.

- `app/picture_sources.py`, `app/composing_sources.py`, `app/render.py`.

## Steps
1. Add Media to the layer-creation control. Place Materials/Library/cached
   candidate sources on media layers, undoably and without rendering. Preserve
   source length; `in` is relative to the owned clip range, not its full file.
   Preserve recordings and all existing placement paths.
2. Reuse the block gesture/command machinery for media: move, both-edge trim,
   Alt-slip for clips, duplicate, delete and layer moves. On split, advance
   the second item's source offset; never shorten or overwrite source files.
3. Add inspector presets (full, top-right, bottom-left, left/right half),
   numeric x/y/w/h, fit, fades and linear volume (0..1, default 0). Mono
   numbers, theme tokens, keyboard access; no native dialogs.
4. Show the selected box on the player. Drag to move, corners to resize;
   save only `box`, undoably, with no rendering during gestures.
5. Add a detached 3D-shot source using composing_sources/shot machinery.
   Placement snapshots the shot and source dependencies; resolve/render only
   on an explicit preview. Keep each shot's own length.
6. Cover placement/undo, clip range/slip, resizing and old UI paths. Review
   light/dark at 1280×720 and 1920×1080. Check missing sources explicitly;
   candidate references depend on the source slide still existing.

## Acceptance
- All original T21.6b acceptance and Steps 3–5 are met.
- A muted inset clip plays exactly its chosen source range.
- Existing features/buttons and graph goldens remain intact.
