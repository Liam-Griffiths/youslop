# T21.2c Project bin: vocabulary editor and multi-select
Phase 21 · Size M · Depends on: T21.2

## Goal
Edit the project label vocabulary and label several bin items in one gesture.

## Read first
- `app/project_bin.py`, `static/js/tabs/bin.js`, `app/schema.py` `BinItem`.
- `app/store.py`, `app/undo.py`, `static/js/palette.js` (app dialog pattern).
- `docs/design/studio-flow.md`, T21.2 and its Log.

## Steps
1. Add a reusable Labels editor: rename, reorder and delete vocabulary entries.
   Reuse `PATCH /api/projects/{pid}/bin/labels` for rename; add reorder/delete
   operations. Rename/delete propagate to every item. Confirm deletion with
   the app dialog. Keep the component usable by Library in T21.4b.
2. Add Shift range and Ctrl/Meta multi-select to the bin grid/list. Apply/remove
   typed labels and number-key labels to the selection in one undo step.
3. Preserve selection and unsaved inspector text across filtering and writes;
   cover keyboard use, rename propagation, reorder, confirmed delete, bulk
   labeling and undo. Add snapshots for vocabulary editing and multi-select.

## Acceptance
- Rename, reorder and delete update vocabulary and item labels consistently.
- One or several items can receive/remove labels by typing or number keys.
- Bulk changes undo together; originals and recordings remain untouched.
