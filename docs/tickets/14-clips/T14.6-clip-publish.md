# T14.6 Clip descriptions, links to the full recording, batch render and upload
Phase 14 · Size M · Depends on: T14.4, T10.7
*Written 2026-11-08 (Claude Opus 5.5) from the owner's clipping request.*

## Goal
Each clip gets a title, a description and tags, with a link to the full recording at the clip's moment. Several clips render in one queued batch and upload as Shorts, or export as files for other platforms.

## Why
Owner: "a description with a link to the full clip." The link sends viewers from the short to the long video, which is the point of clipping.

## Read first
- `app/youtube.py` (`upload_video`, `build_description`, `chapter_points`), `static/js/tabs/render.js` (Review & Publish), `app/jobs.py`, T14.4's Log.

## Steps
1. **Source link.** A recording (shoot source) has an optional `full_url`. When it's a YouTube URL, the clip's link becomes a timestamped link: `https://youtu.be/<id>?t=<in_s>` (or `&t=` for watch URLs). Other URLs are used as they are. A channel can set a default link line, for example "Full episode: {url}".
2. **Description.** A template with `{hook}`, `{title}`, `{url}`, `{timestamp}`, `{channel}` and the channel's default hashtags. Optionally, Claude drafts the title and description from the clip's transcript (opt-in, cost shown, mocked in tests). A Short gets `#Shorts` only when it's 9:16 and at most 3 minutes.
3. **Batch.** On the shoot's Clips screen, "Render selected clips" lists each clip, its aspect and length, and the total, and needs a click. It queues one cancellable job per clip (T9.12), and finished files land in each clip project.
4. **Upload and export.** Upload each clip through `upload_video`, with privacy and schedule per clip, plus captions if T14.5's track exists. "Export files" writes MP4s plus a `.txt` with the title, description and link, for other platforms.
5. **Checks.** Before upload: a link present when the channel requires one, title length, description length, and a 9:16 Short under 3 minutes.

## Acceptance
- A clip at 754.2 s of a recording with `full_url = https://www.youtube.com/watch?v=abc123` gets `https://youtu.be/abc123?t=754` in its description (unit test). An http(s) URL that isn't YouTube is unchanged.
- A batch of 3 fixture clips queues 3 cancellable jobs. Cancelling one leaves the others running (mock render).
- The upload is mocked. The request carries the title, the description with the link, and the Shorts tag for 9:16 only.
