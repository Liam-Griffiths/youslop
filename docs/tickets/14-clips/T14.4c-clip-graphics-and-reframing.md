## Steps
1. Extend validated reframing metadata and Clip/inspector controls to explicit
   crop boxes, paragraph keyframes with short eased moves, and two-speakers
   top/bottom layout. Keep existing static presets and stable paragraph ids.
2. Add an editable Hook initialised from stored `project.clip['hook']`, with
   first-N-seconds/whole-clip duration and overlay block selection. Render a
   top overlay using the channel block theme. Add arbitrary paragraph overlays
   and optional bottom progress bar to the shared source graph, including
   section previews. Remove the temporary graphics rejection only when handled.
3. Expose source caption/word anchors without constructing takes. Preserve
   graphics and crop keyframes through trims/cuts; align them to kept time.
   Include block contents, overlays, source identity and live channel theme in
   clip-only cache keys. Landscape keys/goldens must remain byte-identical.
4. Replace the temporary Clip Publish panel with the existing finish workflow:
   checks, description/full-video link, thumbnail, upload and verification.
   Adapt checks to source-linked clips instead of legacy narration assumptions;
   preserve all ordinary-project buttons. Remove temporary unavailable copy.
5. Harden runtime tests for sub-frame spans, cuts across paragraphs and EOF
   audio handles. Picture proxies must match whole-cut crop/graphics windows;
   Timeline's continuous source-audio mix must match explicit rendering.
6. Extend snapshot fixtures to a landscape video source with portrait moving
   crop/hook, plus silent video and audio-only/manual modes. Reviewer runs
   browser, listening and visual checks outside the sandbox.

- No copied/modified source, source takes or history; no regressions to ordinary
