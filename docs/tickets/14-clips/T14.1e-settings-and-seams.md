## Implementer notes

2026-11-08: Cache version 3 stores padded words. Both workers align ordered lexical
anchors within the two-second overlap; timestamp distance disambiguates repeated
words. They splice through one shared anchor, then repair timing monotonically
before clipping the requested range. Transcript `seam_tail` retains untrimmed
context across cancellation/resume. No lexical agreement falls back to midpoint
ownership: contradictory recognition or words missing from both decodes cannot be
recovered from timestamps alone. This policy handles timestamp jitter of matching
word sequences; it does not claim to correct recognition errors.

The explicit download catalog supports whisper.cpp single-file models; other engines
use install/download instructions and existing local paths. Downloads use launch-time
Settings, never unsaved fields. Publication uses an atomic hard link followed by
removal of the temporary name, refusing an existing destination even across processes.
Detection stays import-free. Runtime reports use loaded Python objects/package versions;
MLX and whisper.cpp explicitly report an unknown execution device when unavailable,
rather than guessing a backend from platform or compiled feature lists.
