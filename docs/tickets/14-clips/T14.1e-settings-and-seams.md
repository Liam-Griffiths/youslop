## Steps
1. Finish Settings: supported explicit model downloads with progress/cancellation,
   configurable cache locations, adapter registration metadata and accurate runtime
   version/device reporting. Never install/download implicitly; Settings fields
   follow restart semantics. Test downloads with fakes, without network calls.
2. Define/test chunk seam ownership when independently decoded timestamps jitter
   across the boundary. Current adapters, transcript worker and Voice retiming use
   midpoint ownership on bounded padded windows; this alone cannot guarantee no
   loss/duplication when two decodes move the same word to opposite sides.
   Preserve repeated real words. Apply the policy to both transcript and take workers.
   Version transcript chunk identity if stored word interpretation changes;
   current `transcripts.CACHE_VERSION` is 2 (voiced fallback/turn metadata).
3. Extend fake-only tests and synthetic UI flows for Settings and seams. Reviewer
   must run the existing T14.1c/T14.1d browser flows: playback, missing engines,
   whole/range/replacement estimates, second-click confirmation, stale-estimate
   invalidation, word edits, recorded-take retiming/cancellation and video controls.
