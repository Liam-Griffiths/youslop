## Steps
1. Finish Settings: supported explicit model downloads with progress/cancellation,
   configurable cache locations, adapter registration metadata and accurate runtime
   version/device reporting. Never install/download implicitly; Settings fields
   follow restart semantics. Test downloads with fakes, without network calls.
2. Define/test chunk seam ownership when independently decoded timestamps jitter
   across the boundary. Current adapters and worker use midpoint ownership on
   bounded padded windows; this alone cannot guarantee no loss/duplication when
   two decodes move the same word to opposite sides. Preserve repeated real words.
3. Replace full-segment fallback with voiced intervals measured from bounded audio,
   retaining `src: stt-seg` and handling silence gracefully. Add pause/energy turn
   markers. Version the chunk cache identity if its stored word interpretation changes.
4. Add an explicit Voice action to retime recorded takes with the same engine.
   Never rewrite/delete audio. Reload under the project lock before applying words,
   rejecting stale results when the selected take changed during inference.
   Keep every word's start/end/src through corrections and overrides for captions.
5. Extend fake-only tests for the above and corresponding synthetic UI flows.
   Reviewer must run T14.1c's snapshot flows in a browser-capable session: audio
   playback, missing engines, whole/range/replacement estimates, second-click
   confirmation, stale-estimate invalidation, word edits and existing video controls.
