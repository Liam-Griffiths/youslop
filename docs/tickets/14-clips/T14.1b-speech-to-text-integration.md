# T14.1b Speech-to-text: audio import and studio integration
Phase 14 · Size L · Depends on: T14.1

## Goal
Finish the user-facing scope split from T14.1 at the approximately 600-line diff limit.
The backend exists; transcription still requires an explicit Python worker call.

## Read first
- T14.1 in full (original acceptance criteria still apply across both tickets).
- `app/stt/`, `app/transcripts.py`, `tests/unit/test_stt.py`.
- `app/footage.py`, `app/setup.py`, `app/settings.py`, Settings, Footage and Voice UI.
- `docs/design/studio-flow.md` and `docs/tickets/NOTES.md`.

## Steps
1. Accept audio-only imports (.mp3 .m4a .wav .flac .ogg .opus), persist their kind,
   generate waveform sprites without video proxies, and support audio in the logger.
   Audit proxy-dependent shot/quality/label operations; keep existing video behavior.
2. Add Settings engine detection/re-check and errors, install links, whisper.cpp model
   folder and executable, default engine/model, and supported explicit model downloads
   with progress. `stt.detect(folder=..., executable=..., refresh=True)` is cheap and
   never imports optional engines. Adapters currently require existing local model paths
   to prevent implicit downloads. Add device selection (faster-whisper currently CPU
   int8), accurate runtime device/version reporting, and configured cache locations.
   Central detection is currently explicit; register metadata when adding adapters.
3. Add the optional setup check and API actions for transcript reads, overrides and
   cancellable `transcripts.start_job`. Resolve default engine/model, allow per-run
   overrides and forward the configured whisper.cpp executable to its adapter.
   Validate requests and source/range existence; never start automatically on import.
4. Show whole/range/re-transcribe controls and an estimate requiring a click before
   starting. Show transcript sentences, coverage and editable words. Link jobs to the
   shoot. A full re-transcribe cancellation currently persists completed chunks, but
   restarting with `retranscribe=True` recomputes them: persist an explicit replacement
   run plan so restart resumes that plan even over existing coverage.
5. Improve segment-only timing from `words.spread` over a segment's full span to voiced
   intervals measured from its bounded audio. Add pause-and-energy turn markers.
   Add the explicit Voice action to retime a recorded take without changing audio.
6. Extend fakes for defaults, timestamp jitter at chunk seams, cancellation during
   whisper.cpp subprocess execution, voiced fallback, audio-only import and UI flows.
   Check model-file changes invalidate inference chunks and old transcript dictionaries
   default missing optional keys. Test the estimate and setup/Settings missing-engine UI.

## Acceptance
- All remaining T14.1 acceptance checks pass, including user defaults and Settings.
- Audio-only sources import, play and transcribe without a video proxy.
- No downloads without a click, and no automatic engine installation or transcription.
- Existing recording/take files and video import behavior are preserved.
