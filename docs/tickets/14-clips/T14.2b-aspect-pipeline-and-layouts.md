## Steps
1. Run all existing golden tests before changing anything. Preserve every
   landscape graph, cache key and layout byte for byte; never regenerate a
   landscape golden. T14.2 adds deterministic segment/proxy/slate key references.
2. Wire `frame_size(project)` through the full render, including intro/outro,
   title slates, presenter, sponsors, stings, stage shots and drawn chunk workers.
   `_render` currently still explicitly requests landscape sizes. Segment graph
   and segment render entry points already resolve omitted sizes from the project.
3. Add native portrait/square essay, title, chapter and caption layouts, or a
   check finding and proportional letterbox fallback. T14.2 temporarily fits
   legacy title/chapter plates and letterboxes the entire essay graph. Replace
   those fallbacks only when native layouts and tests are ready. Avoid shared
   title PNG filenames colliding across aspects.
4. Pass dimensions/aspect to scene/block contexts, including square block
   selection. Unsupported blocks, custom styles, boards and drawn cuts must
   produce a check finding and letterbox, preserving their content. Never stretch
   a landscape composition into another aspect. Ensure camera essay captions
   follow the same policy (`_camera_segment` has its own caption path).
5. Wire `preview_size(project)` through proxies, sponsor/slate previews, Timeline
   state/player geometry, thumbnails and stage previews. Existing no-argument
   callers deliberately retain landscape sizes until this step is done.
6. Include the new geometry/layout inputs in affected non-landscape cache keys
   while leaving landscape key payloads byte-identical. Keep cache keys and
   rendering in agreement. Ensure full renders always read original footage,
   while proxies use preview footage. Cover switching aspect back and forth.
7. Add tests for all affected branches, aspect-specific invalidation, and
   landscape preservation. Keep the portrait/square photographic graph goldens
   from T14.2; update those deliberately if native type layouts change them.
