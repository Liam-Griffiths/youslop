## Steps
1. Wire selected named clips to T14.4's project factory: Make clips creates one
   linked project per selected range, with or without words; never copy originals.
2. Replace bounded 200-word pages with continuous virtual scrolling, preserving
   word drag/keyboard selection across windows and search jumps for hours of text.
3. After a range transcription completes, refine that clip's endpoints to covered
   words automatically; keep the explicit refinement action available. Persist
   suggestion dismissals rather than retaining them only until refresh.
4. Complete manual snapping to nearest >=.25 s envelope pauses beyond the core's
   .4 s outward limit; define behavior when both marks resolve to one pause without
   losing a useful selected range. Word selections retain .4 s outward padding.
5. Run envelope extraction as a cancellable shoot job for long sources. Use prefix
   sums/indexed intervals for sentence-window scoring; avoid repeated envelope
   slicing/scanning. Test cache invalidation, concurrent reads and source changes.
6. Run the UI harness outside the restricted sandbox. Check both modes, long text,
   word/mouse selection, audio/video playback, Space/J/K/L, I/O and arrow scrubbing.
   Extend the browser assertions to confirm saving/reloading and STT completion.
