# T14.4b Clip studio, graphics and whole-cut rendering
Phase 14 · Size L · Depends on: T14.4 (foundations), T14.2c, T12.10a

## Goal
Finish T14.4's clip workflow: Clip / Edit / Publish, editable reframing and
hook graphics, music, Timeline playback and explicit full rendering.

## Read first
- T14.4's Steps, Acceptance and Log; they remain the complete feature contract.
- `app/clip_projects.py`: `create`, `update`, `ranges`, `_paragraphs`,
  `section_graph`, `preview_section`; `app/schema.py`: `Project.kind`, `clip`.
- `app/main.py`: `clip_project_create`, `clip_project_edit`.
- `app/render.py`: `preview_segment`, `_render`, `timeline`, `proxy_segment`,
  `build_mix`, `_audio_graph`; `app/block_overlays.py`, `app/scenes.py` context.
- `static/js/shell.js`, `static/js/core.js`, Timeline and graphics inspector;
  `scripts/ui_snapshots.py`; `docs/design/studio-flow.md`.
- T14.3b for the clip-finder's Make clips handoff (coordinate that scope).

## Steps
1. Add the Clip stage controls and Clip / Edit / Publish bar. Redirect Plan,
   Script and Voice routes for clip projects. Keep other projects unchanged.
   Offer manual/no-transcript clips without requiring speech recognition.
2. Use `ranges(project)` as the shared source of timing for Timeline, proxies,
   mix and full render. No paragraph gaps, head/tail padding, narration take
   files or retirement/history entries. Section preview already bypasses the
   legacy take pipeline; replace the explicit `_render`/`timeline` guards only
   once clip integration exists. Handle audio-only sources and silent video;
   the current section preview explicitly requires a video with audio.
3. Complete reframing: crop-box/keyframe controls, short eased moves between
   paragraph positions and two-speakers top/bottom layout. Current section
   previews support static centre / left third / right third presets only.
4. Add a Hook field initialised from `project.clip['hook']`, first N seconds
   or whole clip, rendered through a top overlay block and channel block theme.
   Support arbitrary paragraph overlays and an optional bottom progress bar.
   Existing section preview intentionally does not render graphics yet.
5. Add the optional existing music bed and preserve -14 LUFS mastering.
   Unify the section graph with full rendering so source audio ranges and
   two-frame audio crossfades match the hard picture cuts. Test very short
   kept spans, cuts across paragraph boundaries and source EOF handles.
6. Keep geometry via `render.frame_size` / `preview_size(project)` and ensure
   source/proxy selection and cache invalidation account for edits, source
   identity, aspect, overlays and channel theme. Never change landscape keys.
7. Wire snapshot fixtures, source/caption word timing and inspector edits.
   Preserve paragraph ids, overlays and reframing through trims; the core
   retains overlapping sentence ids. Never put source audio in take storage.

## Acceptance
- All original T14.4 acceptance, including a moving crop and hook preview.
- Original bytes and mtime unchanged, no take files/history from source audio.
- Clip-finder handoff, Clip stage and Timeline work with and without words.
- Browser and listening/visual acceptance performed by the reviewer if sandboxed.
