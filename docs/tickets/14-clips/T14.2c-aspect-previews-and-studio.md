## Steps
1. Run existing goldens first. Preserve every landscape golden and key byte
   for byte; never regenerate a landscape golden.
2. Use `preview_size(project)` for picture proxies, segment previews, sponsor
   previews and Timeline geometry/state. Slate proxies already use it; preserve
   their new aspect-sensitive keys. Keep no-project callers landscape-compatible.
3. Include geometry/layout inputs in non-landscape proxy keys, including block
   overlays and unsupported-layout fallback paths. Cover aspect switching in
   both directions. Full renders must use originals; proxies must use preview
   footage, including legacy compositions letterboxed from a source canvas.
4. Update Timeline player geometry, thumbnails, Visuals and stage previews.
   Keep all existing controls. Support square block selection wherever the
   studio still maps only portrait versus landscape (including block presets).
5. Ensure text measurement/check findings match native type layouts from
   T14.2b. Unsupported layouts must retain content proportionally, including
   custom and camera overlay sources; never stretch a legacy composition.
   Select an available source aspect for unsupported blocks without a 16:9
   variant; the current recursive fallback assumes a landscape source.
6. Add branch coverage and native caption/essay preview graph tests. Reviewer
   runs photo/title/caption previews at 9:16 and 1:1 and checks the safe areas
   and Shorts UI clearance. Do not claim visual acceptance from graph tests.

## Found in the T14.2b review (2026-11-08, Claude Opus 5.5)
- **Previews are still landscape.** `_build_proxy` calls `preview_size()` with no
  project, so `preview_segment` gave 480×270 and the same cache key for a
  portrait and a square project. Step 2 fixes it; check the key differs per aspect.
- **Overlay blocks without a square layout sink the whole paragraph.** "The
  Tube Mail" paragraph 1 carries a `lower_third_kicker` overlay, which declares
  only 16:9 and 9:16. In square, `blocks.prepare` raises "unsupported aspect
  1:1", and the segment falls back to the landscape render letterboxed, so the
  photo does not fill the square frame (portrait was correct). Pick the
  nearest declared layout for a missing aspect instead: for 1:1, render the
  16:9 layout scaled to the frame width and anchored to the overlay's own
  edge (bottom for lower thirds and captions, top for top overlays), inside
  the safe areas. Only that block falls back; the picture still cover-crops.
  Add a P2 check finding naming the block. Acceptance: the same paragraph in
  square fills the frame with the lower third at the bottom.
