# T15.1 Bundled example channel and video
Phase 15 · Size S · Depends on: T9.13, the example content (built by the reviewer)
*Written 2026-11-08 (Claude Opus 5.5). Owner approved the example the same day: "Under the Street" (Archive theme) with "The Tube Mail", bundled with the app, narrated with text-to-speech so the owner can re-record.*

## Goal
A new user can open a finished example (a channel plus one video) from first-run setup or Home. It opens as an ordinary, editable project in their own data folder, so they can see every stage filled in before making their own.

## Why
An empty app teaches nothing. The example shows research and sources, a script, narration, mixed kinds of picture, blocks, a block theme, the house sponsor read and a short cut, all in one place.

## Read first
- `app/transfer.py` (`export`, `import_`, `read_manifest`, `checked_members`; the `.corkbored` format already carries the project and its channel), `app/setup.py` and `static/js/tabs/setup.js` (T9.13), `static/js/tabs/home.js` ("Open a .corkbored file").
- `app/paths.py` `resource_root`, which locates bundled resources in a packaged app.

## Steps
1. **Bundle location.** `resources/examples/under-the-street.corkbored`, plus `resources/examples/README.md`, which lists every media item with its source URL and licence (all public domain, or CC0 where noted). The reviewer exports the bundle from the example data folder with `transfer.export`. Render caches and finished videos are excluded as usual. Narration takes are included so it plays at once. Keep the file under about 60 MB (downscale pictures to at most 2560 px on the long side if needed).
2. **Offer it.**
   - The first-run setup (T9.13) has a final step: "Open the example channel", or "Start empty".
   - Home's start panel gets a quiet "Open the example" link while no example project exists.
   - Importing uses `transfer.import_` with new ids on conflict, so it never overwrites anything.
   - The project gets `example: true`, shown as a small "Example" badge on Home.
3. **Re-open and remove.** Re-opening the example when one exists asks whether to open the existing copy or import a fresh one. Deleting it is ordinary project deletion, and its narration takes go to history like any other.
4. **Packaging.** Make sure `resources/examples/` ships in the packaged app (check the packaging config the project uses), and that `resource_root()` finds it both in a checkout and in the package.

## Acceptance
- On a fresh data folder, "Open the example channel" imports one channel and one project. The project opens at Review & Publish with every stage filled, and plays in the Timeline (proxies are rebuilt on demand).
- Importing twice gives two projects with different ids; nothing is overwritten.
- Headless Chromium: the setup step, the Home link and the Example badge, with 0 console errors.

## Don't
- No network fetch at import. Never bundle media without a recorded public-domain or CC0 source. Never bundle the owner's music or credentials.
