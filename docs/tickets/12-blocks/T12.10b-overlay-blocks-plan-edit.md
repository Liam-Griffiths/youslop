# T12.10b Block overlays: planning and editing
Phase 12 · Size M · Depends on: T12.10a, T4.4, T12.8
*Written 2026-11-08 (Claude Opus 5.5) from the owner's question; owner approved adding it the same night. Anchors checked against `dev` at that date.*

## Goal
The visual plan proposes a base picture *and* overlays for each paragraph ("footage of the ferry, a name lower third on the word *Hannah*, a kinetic caption on *forty per cent*"), the user sees and edits them on a Graphics row in the Timeline and in the Visuals stage, and checks catch overlays that clash with what is under them.

## Why
Planning shots and executing them, end to end (owner, 2026-11-08). T12.10a can draw an overlay; this makes overlays something the app proposes and the user can steer, by keyboard as well as mouse.

## Steps
1. **Plan output.** The visual plan returns, per paragraph, the base (as today) plus `overlays: [{block_id, vars, on}]`. Rules hold for any format and model: a name or place introduced by the narration gets a lower third; a number gets a kinetic caption *over* footage (no number-badge overlay block exists yet) when the paragraph has footage, and a full-frame data block when it does not ("Numbers are drawn, never searched for"); at most two overlays per paragraph unless the user asks. Conservative lexical rules and variable filling run offline without new LLM calls. Names use explicit picture-note hints, paragraph titles, or capitalised multi-word sequences away from sentence starts. Overlays the plan adds are `by: "auto"`; re-planning never removes or edits `by: "hand"` ones.
2. **Fill from footage.** T11.6's fill keeps choosing the base; when the matched paragraph has a name or number, it also proposes the overlay (as `auto`).
3. **Timeline Graphics row.** A row under the strip (T4.4 style) with each overlay as a bar: select, drag to move, drag the edge to change length (snaps to word starts when timings are not estimates), eye toggle hides overlays from the proxy (`hide=graphics`), Delete removes it. The inspector shows the block's variables as a form (T12.8 form component), position and timing. Keyboard: `G` adds an overlay at the playhead from the block browser in `pick` mode.
4. **Visuals stage.** The paragraph card shows overlay chips over the base preview; "Add graphic" opens the block browser filtered to overlay blocks.
5. **Checks (split to [T12.10c](T12.10c-overlay-blocks-checks.md)).** New findings: overlay text unreadable over its base (contrast measured on the base frame at the overlay's midpoint, quarter size), overlay overlaps captions or a title, overlay outside safe area in the project's aspect, word anchor on an estimated timing (P2, informational).
6. **Presets.** When T12.9 lands first, overlay blocks use presets like any block (a channel's lower-third style); otherwise leave a note in T12.9.

## Acceptance
