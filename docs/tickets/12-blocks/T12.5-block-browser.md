# T12.5 Blocks in the Visuals stage
Phase 12 · Size M · Depends on: T12.1, T9.8, T12.8
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
The Visuals source panel's Templates/Scenes tab lists Corkbored blocks first (built in, packs, mine), filterable by kind and aspect, with our own previews; choosing one shows its variables as a form; third-party blocks appear only when the T2.7c setting is on, in a separate labelled section.

## Why
Blocks are only useful if they are the obvious, fast choice in the flow.

## Read first
- Design guide §8; Scenario C on the studio-flow canvas; T12.1 registry.

## Steps
1. Show 3–6 suggested block posters in Visuals Scenes/Blocks, with More blocks…
   opening T12.8's shared pick browser; keep its grid, filters and local previews.
2. Reuse its variable form and quarter-size trials. Edit opens the saved block
   and values as scratch; Remove clears only cues.blocks. Show the saved trial
   still in Visuals (snapshot switch disables capture). Put CSV row/column
   errors beside the table field as well as in the trial status.
3. Suggest ranked block refs and prefilled vars with pure offline rules over
   narration + visual_note, exposed by a per-slide GET endpoint. Use T12.4
   number extraction; infer maps only from explicit map/where/location notes.
   Suggestions never apply themselves. Bulk application is out of scope.

## Acceptance
- A Short can be built entirely from built-in blocks without opening the third-party section.
