# T12.10c Block overlays: checks over the base picture
Phase 12 · Size M · Depends on: T12.10b
*Split from T12.10b on 2026-11-08 to keep planning/editing reviewable.*

## Goal
Check paragraph graphics against their base picture, captions, titles and safe
areas without drawing new video. Preserve estimated word-anchor confidence.

## Read first
- `app/check.py`: `run`, `_ctx`, `_scene_text`; `app/scenes.py`: `measure_many`.
- `app/block_overlays.py`: `resolved`; `app/render.py`: `_layers`, `_chosen`,
  `_picture_source`, `_proxy_paths`; `app/media/footage.py`: `resolve`.
- `app/block_authoring.py`: text bounds, contrast and portrait safe-area rules.
- `tests/unit/test_block_overlays.py`, `tests/unit/test_check.py`.
- T12.10b's Log and the owner's reviewer notes from 2026-11-08.

## Steps
1. Use resolved graphics and the existing timeline layers. Flag a word anchor
   with `src == 'est'` as P2 information. Do not change stored timing.
2. Approximate the base at each overlay midpoint at quarter size using an existing
   cheap still/thumb path (the nearest available clip thumb inside footage in/out).
   Respect held picture groups and crop/focal point. Never sample a proxy already containing graphics. If a
   source has no cheap base frame, skip contrast with an informational note;
   never render a segment or start Chromium just to obtain it.
3. Estimate text contrast against the sampled base using the resolved channel
   ink/default colours and the block's position region, accounting for the
   core blocks' opaque panels. Reuse cached text geometry when available;
   explain missing geometry with an info note rather than inventing text bounds.
4. Check spatial and temporal overlap with captions/titles from timeline
   layers, and text bounds against block `safe_areas` and position in both
   aspects (including portrait UI exclusions). Do not flag temporal overlap
   alone when the text occupies different areas of the frame. Position regions
   may approximate collisions without geometry; safe-area findings require
   cached text bounds, otherwise report that safe areas were not measured.
5. Unit tests use Pillow white/dark frames and mocked geometry/frame providers.
   Prove white text on white fires and on dark does not, panel backgrounds are
   respected, held-picture sources are sampled correctly, missing frames skip,
   estimates remain informational, and no rendering/model/network call occurs.

## Acceptance
- White-on-white and dark-background tests behave as specified above.
- Real spatial collisions and unsafe text are reported; nonintersecting text
  is not reported merely because it shares screen time.
- Default checks stay cheap and deterministic; no new video or browser work.

## Implementer notes

2026-11-08: reviewer notes narrow Steps 2–4 to cheap, approximate checks: use
existing local stills/thumbs, resolved ink and overlay position regions without
rendering the block. A single quarter-size source frame grab is permitted but
not required; this implementation reads only existing stills/thumbs, never
decodes video. The six built-in text overlays all have opaque panels, including
kinetic captions. Their shared CSS derives panel from 95% resolved bg / 5% ink,
rather than the standalone `default_colors.panel`. Use `_layers` on storyboard
segments inside Check; the public storyboard does not expose timeline layers.
