## Goal
Finish channel management and promotion for presets without copying block code
into project or channel folders.

## Steps
1. Add a channel page Blocks section using the shared browser's channel mode:
   pinned blocks first, then presets; Add blocks, rename, reorder, unpin.
   Preserve existing channel actions and the hand-written schema serializers.
2. Add explicit project → channel promotion (copy values, new channel preset id).
   Channel → Mine uses only the existing duplicate path when the user explicitly
   asks to change code. Built-ins remain disabled pending T12.8c's owner decision;
   explain that gating in the UI. Never copy code into channel/project folders.
3. Rank script/plan block suggestions toward channel pins and presets of the same
   block kind. Keep other suggestions; do not auto-apply or call an LLM.
4. Exercise save project/channel/both → select → edit → counted Update slides
   using this preset, including Graphics. Existing slide vars remain authoritative.
   Ensure positions, timing, word anchors and hand ownership survive updates.
5. Check responsive/keyboard UI and snapshot fixtures with one channel pin and
   preset. Missing blocks stay labelled with saved values; no KeyError.

## Acceptance
- Channel pins/presets can be managed and appear first in its projects.
- Project presets remain isolated until explicitly promoted.
- Promotion respects built-in duplicate gating.
- Suggestions prefer matching channel choices without dropping alternatives.
