# T12.3 Core block set v1
Phase 12 · Size L · Depends on: T12.2
*Written 2026-10-31 (Claude Opus 5.5) from the owner's brief; anchors checked against `dev` at that date.*

## Goal
About 30 Corkbored blocks ship built in, each in 16:9 and 9:16, covering what documentaries, explainers, vlogs and Shorts need, designed to the Instrument look by default and recolourable through channel tokens.

## Why
This is the replacement for the third-party catalog. Coverage matters more than flourish: a creator should rarely need anything else.

## Read first
- The design guide; the Rostrum and studio-flow canvases; the drawn-cut looks (Loudmouth, Ticker, Casefile...) for style range; T5.x migrations (which blocks they already imply).

## Steps
Ship in reviewable batches with `block check` output in the log (the owner reviews and commits):
1. **Text:** lower third (3 styles), title card, chapter card, quote card, pull quote over picture, kicker + headline, end card, kinetic caption styles (3).
2. **Numbers and data:** number slam, stat comparison (A vs B), line chart, bar chart, bar race, percentage ring, simple table, timeline of dates.
3. **Explainers:** step list, callout arrow over picture, highlight on a document scan, map highlight (an existing local map picture, including `maps.py` output; never fetch tiles), before/after wipe, split comparison, labelled diagram over a still.
4. **Channel:** subscribe/follow card (generic: no platform logos unless the platform's brand rules allow; text "Subscribe"), next-video card, sponsor short and long reads (from T10.3).
Each block: variables documented, sample values, both aspects, preview set.

## Acceptance
- At least 30 blocks pass `block check` in both aspects; a contact sheet of all posters is in `docs/blocks/core-v1.png`.

## Don't

## Implementer notes
- Design each block from a short written brief (purpose, variables, motion beats) before code; keep briefs in `docs/blocks/briefs/`.
- Batch 1 scope (owner, 2026-10-31): the 12 Text blocks only, reusing
  `chapter`. Both aspects, Instrument look, local fonts and channel tokens.
  Chromium is unavailable in the implementer's sandbox: run static checks
  per block; the reviewer runs full browser checks and generates previews
  and the contact sheet. Do not create `docs/blocks/core-v1.png` in this batch.

- Batch 2 scope (2026-11-01): the 8 Numbers and data blocks. Since T2.10 every
  block renders through the scene builder: declare motion with `data-layer` /
  `data-motion` (see `docs/blocks/format.md`, `docs/scene-builder.md`, and the
  batch 1 blocks as converted in T2.10). Reuse the shared motions Ticker added
  (T5.3c, `static/scene/cuts/ticker.html`): `atlas` for counting numbers,
  `reveal` for lines and bars. No per-frame capture: a bar race reorders in a few
  discrete steps (one layer per bar, `data-path` keys), a percentage ring fills by
  an atlas or a stepped reveal. A capture window only with a stated reason, within
  `budget`. Both aspects, Instrument look, channel tokens, sample values. Chromium
  is unavailable: static checks per block; the reviewer runs browser checks,
  timings and the contact sheet.

- Batch 3 scope (2026-11-01): the 7 Explainer blocks. Same builder rules as
  batch 2 and its review: type floor 44 px for labels/values at 1080, titles as
  batch 1, mono/44 px rows on 1.4 em / 62 px line boxes (`data-fit` truncates on a
  1 px overflow), footer and content inside the title-safe area. Pictures are a
  `picture` variable drawn by ffmpeg as native media (`data-media`, see Group Chat
  and Casefile scenes) with cover/focal/dim; the before/after wipe is two media
  layers with the shared `wipe` motion; the callout arrow and highlight boxes are
  SVG layers with `reveal`/`wipe`, never per-frame capture. Map highlight takes an existing local map picture (including
  `app/maps.py` output) plus a region or pin; it never calls the network-backed
  map generator. Sample stills: generate simple local
  placeholder images (Pillow, committed under the block folder); no network, no
  third-party images. Both aspects, sample values, briefs first. Chromium is
  unavailable: static checks; the reviewer runs browser checks and posters.
