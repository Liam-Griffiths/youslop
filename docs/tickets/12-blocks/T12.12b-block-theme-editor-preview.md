# T12.12b Block themes: editor and live previews
Phase 12 · Size M · Depends on: T12.12a, T12.11
*Written 2026-11-08 (Claude Opus 5.5) from owner feedback.*

## Goal
A channel, or a standalone video, gets a "Block theme" panel for picking colours, fonts, radius and pace. It shows a live sheet of real blocks drawn in that theme. The Blocks screen can preview any block "as" a channel or project theme.

## Why
Owner, 2026-11-08: "I want to theme the blocks per channel or standalone video, and I want to be able to preview those." T12.12a resolves the tokens. Without a way to see them, a theme is a guess.

## Read first
- T12.12a's Log (token names, `variables()` `block` group, `prepare(theme=)`).
- `static/js/tabs/channels.js` (the theme strip `pickTheme`, House look panel), `static/js/tabs/render.js` (the "Look, sound and opening" panel), `static/js/tabs/blocks_browser.js` (preview requests, presets UI).
- `app/block_library.py` (`make_posters`, `preview`), `docs/design/studio-flow.md` (inspector rows, segmented controls, source labels).

## Steps
1. **Theme sheet API.** `POST /api/blocks/theme-sheet` takes `{scope: 'channel'|'project', id, overrides?}` and returns posters for a fixed set of six representative blocks: title card, a lower third (drawn over the sample still), a data block, a quote, a step list and an end card. Each poster is drawn at its midpoint at quarter size in the chosen aspect. Unsaved `overrides` let the panel preview before saving. It's cached by the resolved theme hash, with one request in flight per session (reuse `preview`'s sequencing). Six cold posters should take about 1.5 s; say so in the Log with the measured time.
2. **Editor panel.** "Block theme" sits on the channel page beside House look, and in a standalone project's Look settings (T13.4 moves it to the style area; until then, put it where the Look panel is). A channel project shows the channel's values with source labels and a per-token "override here" or "reset" control.
   - **Colours:** swatch inputs (`<input type="color">` styled to the app, plus the hex value). "Start from a theme" applies a `themes.THEMES` entry's colours.
   - **Fonts:** two selects listing the bundled and pack faces, each option rendered in its own face.
   - **Radius, weight and pace:** segmented controls or sliders.
   - Contrast warnings from T12.12a show inline next to the token.
3. **Live sheet.** Under the controls, the six-poster sheet refreshes about 300 ms after a change, using unsaved overrides. Clicking a poster opens T12.11's expanded player on that block in this theme, playing.
4. **Preview as.** The Blocks screen gets a "Preview as" select: Default, each channel, and the current project when opened from one. Posters, hover motion, trials and the expanded player all use that theme. Grid posters for non-default themes are drawn on demand (visible cards first), never all at once, and are cached.
5. **Snapshots.** Add routes or steps for the channel theme panel and the Blocks screen previewing as the snapshot channel.

## Acceptance
- In headless Chromium, changing the channel accent in the panel updates the sheet's posters within a few seconds without saving. Saving persists it, and a channel project's panel shows `channel` as the source. Overriding the accent in the project shows `project`, and resetting returns to `channel`.
- "Preview as" the snapshot channel on the Blocks screen changes the `title_card` poster: a pixel check on the accent rule.
- The 0-console-error snapshot run passes, including the new routes.

## Don't
- Don't re-render whole videos or segment proxies from the panel. The sheet is block posters only.
- Don't add native-looking selects or `background:` shorthands on selects (see NOTES.md, dropdowns).
- Don't touch photographic Look controls (grade, vignette, drift) here.
